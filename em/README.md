# 幾何代数による電磁気学

電磁気学と特殊相対論を幾何代数で扱う記事シリーズです（準備中）。

検討の経緯は[MEMO.md](MEMO.md)にまとめています。

## 構想

[クリフォード解析](../clif-analysis/README.md)では、ラプラシアンの平方根となるディラック作用素$D$を軸に、複素解析を組み直して一般次元へ進みました。本シリーズはその物理側への展開で、同じ作用素と基本定理・積分公式を電磁場に使います。

ベクトル解析では、電磁気学の法則は発散と回転に分けた4本の式で書かれます。この分離は、四元数の積を内積とベクトル積に分けた経緯（[四元数が脇役になった歴史的経緯](../qua/history.md)）に由来します。幾何代数では電場と磁場を1つの量$F$にまとめ、マクスウェル方程式を1本の式として書けます。4本の式はそのグレード成分として回収され、磁場がもともと2ベクトルであることから、擬ベクトルという例外的な扱いも不要になります。静的な場では、クーロンの法則とビオ＝サバールの法則が3次元のクリフォード解析の積分公式そのものとして現れます。

シリーズの軸は、作用素の係数の2乗の符号です。クリフォード解析の作用素と電磁場の作用素は同じ形をしており、係数の2乗が$-1$ならラプラシアン（楕円型、正則関数）、$+1$なら波動作用素（双曲型、電磁波）が現れます。前半は3次元の$\operatorname{Cl}_{3,0}(\mathbb R)$で書き、後半で時空代数$\operatorname{Cl}_{1,3}(\mathbb R)$に進んで、前半の形式をその偶部分として回収します。ローレンツ変換は時空の回転子として扱います。

スピノルとディラック方程式は本シリーズでは扱わず、[全体構想](../PLAN.md)の「時空代数とディラック方程式」に委ねます。
