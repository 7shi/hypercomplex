# 幾何代数による電磁気学

電磁気学と特殊相対論を幾何代数で扱う記事シリーズです（全7回、下書き）。

## 記事

1. [静電場と静磁場](01-static.md) — 電荷・電流とローレンツ力から電場と磁場を導入したうえで、クーロンの法則とビオ＝サバールの法則を、源$\rho-\boldsymbol J/c$にコーシー核を掛ける1本の積分公式にまとめ、ベクトル部が電場、2ベクトル部が磁場の$Ic$倍になることを示します。スカラー部は定常電流の条件で消えます。核の$4\pi$は$|S^2|$、$D$を掛けたグレード成分が静的な場の4本の式、基本定理のグレード成分がガウスの法則とアンペールの法則の積分形です。点電荷と直線電流の場を例として求めます。
2. [マクスウェル方程式](02-maxwell.md) — 電荷の保存・変位電流・電磁誘導から時間変化する場の法則を導き、作用素$\mathcal D=\partial_0+D$で、マクスウェル方程式を$\mathcal DF=(\rho-\boldsymbol J/c)/\varepsilon_0$の1本の式にまとめます。四元数解析の作用素と同じ形で係数の2乗が$+1$に替わり、共役との積が波動作用素になります。連続の式と波動方程式を導き、波の速さが$1/\sqrt{\varepsilon_0\mu_0}$であることから光が電磁波であることを確認します。
3. [電磁波とエネルギーの流れ](03-waves.md) — 平面波を進行方向の冪等元$(1+\hat{\boldsymbol k})/2$の像として求め、$F^2=0$を示します。擬スカラーの指数関数が円偏光を表すこと、$\frac{\varepsilon_0}2FF^\dagger=u+\boldsymbol S/c$とポインティングの定理を扱い、コンデンサーと太陽光の例でエネルギー密度とエネルギーの流れの大きさを確かめます。
4. [時空代数とマクスウェル方程式](04-spacetime.md) — 光速度不変から特殊相対論の要請と不変な間隔を確認し、$\operatorname{Cl}_{1,3}(\mathbb R)$でマクスウェル方程式を$DF=\mu_0cJ$と書き、$\gamma_0$を掛けて前半の式に戻します。この操作は四元数解析で$e_0$を掛けた操作と同じで、空間の生成元の2乗の符号が楕円型と双曲型を分けます。符号数の選択にも触れます。
5. [ローレンツ変換と回転子](05-lorentz.md) — 2ベクトルの指数関数による回転子で、空間の回転（三角関数）とブースト（双曲線関数）を作ります。$F$を回転子で挟んで電場と磁場の混合、不変量、ドップラー因子を導き、ローレンツ力を$F\cdot v$として書きます。時間の遅れ、速度の合成則、電気力と磁気力の相対性、低速での非相対論的な運動方程式への帰着も扱います。
6. [ポテンシャルとエネルギー運動量](06-potential.md) — 時空のポテンシャル$A$で$F=D\wedge A$とし、$D\cdot A$をゲージの自由度として扱います。ローレンスゲージでは$\square A=\mu_0cJ$です。エネルギー運動量$T(a)=-\frac{\varepsilon_0}2FaF$の発散がローレンツ力の密度になることを示し、放射圧を例に電磁場の運動量を扱います。
7. [双曲型の基本解と性質の仕分け](07-retarded.md) — 遅延基本解と遅延ポテンシャルを導いて因果律と放射の意味を説明し、クリフォード解析の性質のうち、双曲型で形を保つもの（成分の方程式・基本定理）、替わるもの（積分公式・一意性の根拠）、失われるもの（平均値の性質・最大値原理・リウヴィルの定理・一致の定理）、次元で変わるもの（ホイヘンスの原理）を仕分けます。

検討の経緯は[MEMO.md](MEMO.md)にまとめています。

## 構想

想定読者は、幾何代数とクリフォード解析（[クリフォード解析](../clif-analysis/README.md)シリーズ）にはある程度馴染みがあり、電磁気学は本シリーズで入門する人です。そのためクリフォード代数側の記述は既知として簡潔に済ませ、電磁気学側は電荷・電流・力といった基本的な概念から、物理的な意味や具体例を添えて説明します。扱うのは真空中の電磁場で、物質中の場は扱いません。

[クリフォード解析](../clif-analysis/README.md)では、ラプラシアンの平方根となるディラック作用素$D$を軸に、複素解析を組み直して一般次元へ進みました。本シリーズはその物理側への展開で、同じ作用素と基本定理・積分公式を電磁場に使います。

ベクトル解析では、電磁気学の法則は発散と回転に分けた4本の式で書かれます。この分離は、四元数の積を内積とベクトル積に分けた経緯（[四元数が脇役になった歴史的経緯](../qua/history.md)）に由来します。幾何代数では電場と磁場を1つの量$F$にまとめ、マクスウェル方程式を1本の式として書けます。4本の式はそのグレード成分として回収され、磁場がもともと2ベクトルであることから、擬ベクトルという例外的な扱いも不要になります。静的な場では、クーロンの法則とビオ＝サバールの法則が3次元のクリフォード解析の積分公式そのものとして現れます。

シリーズの軸は、作用素の係数の2乗の符号です。クリフォード解析の作用素と電磁場の作用素は同じ形をしており、係数の2乗が$-1$ならラプラシアン（楕円型、正則関数）、$+1$なら波動作用素（双曲型、電磁波）が現れます。前半は3次元の$\operatorname{Cl}_{3,0}(\mathbb R)$で書き、後半で時空代数$\operatorname{Cl}_{1,3}(\mathbb R)$に進んで、前半の形式をその偶部分として回収します。ローレンツ変換は時空の回転子として扱います。

スピノルとディラック方程式は本シリーズでは扱わず、[全体構想](../PLAN.md)の「時空代数とディラック方程式」に委ねます。
