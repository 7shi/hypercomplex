# 検証コード

幾何代数による電磁気学の記事の数式を検証するPythonスクリプトです。プロジェクトルートで `uv sync` により環境を構築し、`uv run em/check/<ファイル名>` で実行します。クリフォード代数の実装は`common.clifford`（`src/common/clifford.py`、$\operatorname{Cl}_{p,q}(\mathbb R)$のビットマスク実装）を使います。

- [01-static.py](01-static.py) — [01-static.md](../01-static.md)の数式。被積分関数$\boldsymbol r(\rho-\boldsymbol J/c)/\varepsilon_0$のグレード成分がクーロンとビオ＝サバールの被積分関数になること、スカラー部についての恒等式$\boldsymbol r\cdot\boldsymbol J/|\boldsymbol r|^3=\nabla_{\boldsymbol y}\cdot(\boldsymbol J/|\boldsymbol r|)-\nabla\cdot\boldsymbol J/|\boldsymbol r|$、$D|\boldsymbol x|^{-1}=-\boldsymbol x/|\boldsymbol x|^3$と$-D(\varphi-c\boldsymbol A)$の成分、ガウス型の源（$\rho\propto e^{-r^2}$、$\boldsymbol J=\nabla\times(e^{-r^2}e_3)$）でスカラー部の消滅・$DF=(\rho-\boldsymbol J/c)/\varepsilon_0$・4本の式（記号計算）と積分公式（数値積分）、積分形のグレード成分を確認します。
- [02-maxwell.py](02-maxwell.py) — [02-maxwell.md](../02-maxwell.md)の数式。$\mathcal DF$のグレード成分とマクスウェル方程式の同値性、$(\partial_0-\sum a_l\partial_l)(\partial_0+\sum a_l\partial_l)=\partial_0^2-\sum a_l^2\partial_l^2$（$e_l$と$h_l=e_0e_l$）、$\bar{\mathcal D}$を源に掛けた成分（連続の式）と電場・磁場の波動方程式を確認します。
- [03-waves.py](03-waves.py) — [03-waves.md](../03-waves.md)の数式。$\mathcal DF(x_0-\hat{\boldsymbol k}\cdot\boldsymbol x)=(1-\hat{\boldsymbol k})F'$、冪等元$(1\pm\hat{\boldsymbol k})/2$、平面波の条件、$F^2$の成分、擬スカラーの指数関数による円偏光と$e^{-I\hat{\boldsymbol k}\theta}$への書き換え、$\frac{\varepsilon_0}2FF^\dagger=u+\boldsymbol S/c$、$\langle\mathcal D(FF^\dagger)\rangle_0=2\langle(\mathcal DF)F^\dagger\rangle_0$とポインティングの定理を確認します。
- [04-spacetime.py](04-spacetime.py) — [04-spacetime.md](../04-spacetime.md)の数式。$\operatorname{Cl}_{1,3}(\mathbb R)$の逆基底と$D^2=\partial_0^2-\Delta$、$\sigma_k=\gamma_k\gamma_0$と偶部分代数、$x\gamma_0=x_0+\boldsymbol x$、$\gamma_0D=\mathcal D$・$D(\gamma_0H)=\bar{\mathcal D}H$、$I\sigma_k$の基底表示、$\gamma_0J=c(\rho-\boldsymbol J/c)$、$D\cdot F$・$D\wedge F$の分割と$D\cdot(D\cdot F)=0$を確認します。
- [05-lorentz.py](05-lorentz.py) — [05-lorentz.md](../05-lorentz.md)の数式。2ベクトルの指数関数（双曲線関数と三角関数）、ブーストと回転の作用、ラピディティの加法性、観測者の見る電場と磁場の変換公式、$F^2$の不変性、ローレンツ力$\frac qcF\cdot v$の成分、平面波のドップラー因子$e^{-\varphi}$を確認します。
- [06-potential.py](06-potential.py) — [06-potential.md](../06-potential.md)の数式。$\gamma_0A=\varphi-c\boldsymbol A$、$D\wedge A$と$D\cdot A$の成分、ゲージ変換、$D(D\wedge A)=D^2A-D(D\cdot A)$とポテンシャルの波動方程式、静的な場合の$DA=-D_3P$、$T(a)=-\frac{\varepsilon_0}2FaF$がベクトルで対称なこと、$T(\gamma_0)\gamma_0=\frac{\varepsilon_0}2FF^\dagger$、$\sum\partial_\mu T(\gamma^\mu)=-\frac1cF\cdot J$を確認します。
- [07-retarded.py](07-retarded.py) — [07-retarded.md](../07-retarded.md)の数式。$\square(f(x_0-r)/r)=0$と原点での流束、$D$の基本解の形と$(\gamma_0+\boldsymbol n)^2=0$、遅延ポテンシャルのローレンツゲージに使う恒等式、空間2次元の基本解、球面平均の公式とキルヒホッフの公式（多項式の初期値）、平面波による平均値の性質などの反例を確認します。
- [memo-signature.py](memo-signature.py) — [MEMO.md](../MEMO.md)の構成案の数式。$\operatorname{Cl}_{3,0}(\mathbb R)$で$\mathcal D(\boldsymbol E+Ic\boldsymbol B)$のグレード成分がマクスウェル方程式の4本の式になること（右辺$(\rho-\boldsymbol J/c)/\varepsilon_0$）と連続の式、$\bar{\mathcal D}\mathcal D=\partial_0^2-\Delta$、$\frac{\varepsilon_0}2FF^\dagger=\frac{\varepsilon_0}2(|\boldsymbol E|^2+c^2|\boldsymbol B|^2)+\varepsilon_0c\,\boldsymbol E\times\boldsymbol B$、パラベクトルのノルム$p\bar p$とワイル表現のガンマ行列が$(+,-,-,-)$を与えること（下のブロックを$-\bar\sigma^\mu$にすると$(-,+,+,+)$）、$\operatorname{Cl}_{1,3}(\mathbb R)$で$\sigma_k=\gamma_k\gamma_0$が$\operatorname{Cl}_{3,0}$の生成元になり$\sigma_1\sigma_2\sigma_3=I$、$\gamma_0D=\partial_0+\sum\sigma_k\partial_k$、$D^2=\partial_0^2-\Delta$（$\operatorname{Cl}_{3,1}$では符号が逆）、時空の2ベクトル$F$で$\gamma_0DF$が$\operatorname{Cl}_{3,0}$の式に戻り$DF=\mu_0cJ$（$J=c\rho\gamma_0+\sum J_k\gamma_k$）となることを確認します。
