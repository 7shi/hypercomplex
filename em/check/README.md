# 検証コード

幾何代数による電磁気学の記事の数式を検証するPythonスクリプトです。プロジェクトルートで `uv sync` により環境を構築し、`uv run em/check/<ファイル名>` で実行します。クリフォード代数の実装は`common.clifford`（`src/common/clifford.py`、$\operatorname{Cl}_{p,q}(\mathbb R)$のビットマスク実装）を使います。

- [01-static.py](01-static.py) — [01-static.md](../01-static.md)の数式。被積分関数$\boldsymbol r(\rho-\boldsymbol J/c)/\varepsilon_0$のグレード成分がクーロンとビオ＝サバールの被積分関数になること、スカラー部についての恒等式$\boldsymbol r\cdot\boldsymbol J/|\boldsymbol r|^3=\nabla_{\boldsymbol y}\cdot(\boldsymbol J/|\boldsymbol r|)-\nabla\cdot\boldsymbol J/|\boldsymbol r|$、$D|\boldsymbol x|^{-1}=-\boldsymbol x/|\boldsymbol x|^3$と$-D(\varphi-c\boldsymbol A)$の成分、ガウス型の源（$\rho\propto e^{-r^2}$、$\boldsymbol J=\nabla\times(e^{-r^2}e_3)$）でスカラー部の消滅・$DF=(\rho-\boldsymbol J/c)/\varepsilon_0$・4本の式（記号計算）と積分公式（数値積分）、積分形のグレード成分、SIの定数と単位（$1/\sqrt{\varepsilon_0\mu_0}=c$、$\boldsymbol E$と$c\boldsymbol B$が同じ単位）、磁場の力が仕事をしないことと電位による仕事、一様な球の電荷の電場とガウスの法則、直線電流の磁場$\mu_0I/2\pi r$、2ベクトル$i\boldsymbol B$によるローレンツ力の表示$\boldsymbol v\times\boldsymbol B=\frac12((i\boldsymbol B)\boldsymbol v-\boldsymbol v(i\boldsymbol B))$、一様な面電荷の電場$\sigma/2\varepsilon_0$を確認します。
- [02-maxwell.py](02-maxwell.py) — [02-maxwell.md](../02-maxwell.md)の数式。$\mathcal DF$のグレード成分とマクスウェル方程式の同値性、$(\partial_0-\sum a_l\partial_l)(\partial_0+\sum a_l\partial_l)=\partial_0^2-\sum a_l^2\partial_l^2$（$e_l$と$h_l=e_0e_l$）、$\bar{\mathcal D}$を源に掛けた成分（連続の式）と電場・磁場の波動方程式、コンデンサーの変位電流、真空の平面波での回転の2本の積分形、$1/\sqrt{\varepsilon_0\mu_0}$の値を確認します。$D^2=\Delta$のグレード成分として$\nabla\times\nabla\varphi=0$、$\nabla\cdot(\nabla\times\boldsymbol V)=0$、回転の回転の公式が得られることも確認します。時間発展の式が2つの発散の制約を保つこと、$f(z-ct)$が波動方程式の解であることも確認します。
- [03-waves.py](03-waves.py) — [03-waves.md](../03-waves.md)の数式。$\mathcal DF(x_0-\hat{\boldsymbol k}\cdot\boldsymbol x)=(1-\hat{\boldsymbol k})F'$、冪等元$(1\pm\hat{\boldsymbol k})/2$、平面波の条件、$F^2$の成分、擬スカラーの指数関数による円偏光と$e^{-i\hat{\boldsymbol k}\theta}$への書き換え、$\frac{\varepsilon_0}2FF^\dagger=u+\boldsymbol S/c$、$\langle\mathcal D(FF^\dagger)\rangle_0=2\langle(\mathcal DF)F^\dagger\rangle_0$とポインティングの定理、波面の移動と$f\lambda=c$、$\boldsymbol E,\boldsymbol B,\hat{\boldsymbol k}$の右手系、平行板コンデンサーのエネルギー、太陽光の電場と磁場の振幅を確認します。電気と磁気の双対性$Fe^{i\alpha}$、$u^2-|\boldsymbol S|^2/c^2=(\varepsilon_0/2)^2|F^2|^2\ge0$、空間1次元のダランベールの解$P_+f(x_0-x_1)+P_-g(x_0+x_1)$も確認します。$P_-F$が一般にスカラー部を持つこと、平面波の$FF^\dagger=4|\boldsymbol E|^2P_+$、双対回転した源の磁荷と磁流にあたる成分も確認します。
- [04-spacetime.py](04-spacetime.py) — [04-spacetime.md](../04-spacetime.md)の数式。$\operatorname{Cl}_{1,3}(\mathbb R)$の逆基底と$D^2=\partial_0^2-\Delta$、$\sigma_k=\gamma_k\gamma_0$と偶部分代数、$x\gamma_0=x_0+\boldsymbol x$、$\gamma_0D=\mathcal D$・$D(\gamma_0H)=\bar{\mathcal D}H$、$i\sigma_k$の基底表示、$\gamma_0J=c(\rho-\boldsymbol J/c)$、$D\cdot F$・$D\wedge F$の分割と$D\cdot(D\cdot F)=0$、光の信号がヌルで世界線の接ベクトルが時間的であることを確認します。観測者の時間軸による分解$\boldsymbol E=\frac12(F-\gamma_0F\gamma_0)$、$ic\boldsymbol B=\frac12(F+\gamma_0F\gamma_0)$も確認します。電場の面$\sigma_k$と磁場の面$i\sigma_k$が互いの直交補空間で、$F\mapsto iF$が両者を入れ替えることも確認します。$x_1$方向のローレンツ変換が間隔の2乗を保つこと、同時な2事象の時間差$-\gamma\beta\Delta x_1$、低速でガリレイ変換に近づくことも確認します。
- [05-lorentz.py](05-lorentz.py) — [05-lorentz.md](../05-lorentz.md)の数式。2ベクトルの指数関数（双曲線関数と三角関数）、ブーストと回転の作用、ラピディティの加法性、観測者の見る電場と磁場の変換公式、$F^2$の不変性、ローレンツ力$\frac qcF\cdot v$の成分、平面波のドップラー因子$e^{-\eta}$、時間の遅れと速度の合成則、純粋な電場をブーストしたときの$\boldsymbol B'=\boldsymbol u\times\boldsymbol E'/c^2$と動く点電荷のビオ＝サバールの法則、静止した電荷が動く観測者に電流として見えること、$\gamma mc^2$の展開を確認します。直感的な説明として、回転した基底$\gamma_\mu'=R\gamma_\mu\tilde R$が同じ関係式を満たすこと、光の向き$\gamma_0\pm\gamma_1$がブーストで$e^{\pm\eta}$倍になること、回転子の運動方程式$dR/d\tau=\frac q{2mc}FR$と一様な電場（双曲運動）・一様な磁場（サイクロトロン運動）の解も確認します。ブーストの生成元の交換子$\sigma_1\sigma_2-\sigma_2\sigma_1=2i\sigma_3$と、ポインティングベクトルの向きのブーストによる場の標準形（$\boldsymbol E'\parallel\boldsymbol B'$、数値）も確認します。観測者の座標が$x_0'=\gamma(x_0-\beta x_1)$、$x_1'=\gamma(x_1-\beta x_0)$となること、$\gamma mc^2=(mU)\cdot(c\gamma_0)$、$(i\sigma_k)\cdot\gamma_0=0$、純粋な磁場を同行する観測者が見た電場$\boldsymbol E'_\perp=\gamma\boldsymbol v\times\boldsymbol B$も確認します。
- [06-potential.py](06-potential.py) — [06-potential.md](../06-potential.md)の数式。$\gamma_0A=\varphi-c\boldsymbol A$、$D\wedge A$と$D\cdot A$の成分、ゲージ変換、$D(D\wedge A)=D^2A-D(D\cdot A)$とポテンシャルの波動方程式、静的な場合の$DA=-D_3P$、$T(a)=-\frac{\varepsilon_0}2FaF$がベクトルで対称なこと、$T(\gamma_0)\gamma_0=\frac{\varepsilon_0}2FF^\dagger$、$\sum\partial_\mu T(\gamma^\mu)=-\frac1cF\cdot J$、平面波の運動量の流れと放射圧（太陽光の値）を確認します。$\gamma_0\cdot T(\gamma_0)=u$、偶部分での$\boldsymbol J\times\boldsymbol B=\frac12((i\boldsymbol B)\boldsymbol J-\boldsymbol J(i\boldsymbol B))$、固定した経路での電場の積分と$\varphi$・$\boldsymbol A$の関係も確認します。
- [07-retarded.py](07-retarded.py) — [07-retarded.md](../07-retarded.md)の数式。$\square(f(x_0-r)/r)=0$と原点での流束、$D$の基本解の形と$(\gamma_0+\boldsymbol n)^2=0$、遅延ポテンシャルのローレンスゲージに使う恒等式、空間2次元の基本解、球面平均の公式とキルヒホッフの公式（多項式の初期値）、平面波による平均値の性質などの反例、放射の$1/r$の項が球面を通して有限のエネルギーを運ぶことを確認します。放射の部分がヌル場になるための恒等式$(k\wedge a)^2=(k\cdot a)^2-k^2a^2$（$k=D(x_0-r)$は光的）も確認します。
- [memo-signature.py](memo-signature.py) — [MEMO.md](../MEMO.md)の構成案の数式。$\operatorname{Cl}_{3,0}(\mathbb R)$で$\mathcal D(\boldsymbol E+ic\boldsymbol B)$のグレード成分がマクスウェル方程式の4本の式になること（右辺$(\rho-\boldsymbol J/c)/\varepsilon_0$）と連続の式、$\bar{\mathcal D}\mathcal D=\partial_0^2-\Delta$、$\frac{\varepsilon_0}2FF^\dagger=\frac{\varepsilon_0}2(|\boldsymbol E|^2+c^2|\boldsymbol B|^2)+\varepsilon_0c\,\boldsymbol E\times\boldsymbol B$、パラベクトルのノルム$p\bar p$とワイル表現のガンマ行列が$(+,-,-,-)$を与えること（下のブロックを$-\bar\sigma^\mu$にすると$(-,+,+,+)$）、$\operatorname{Cl}_{1,3}(\mathbb R)$で$\sigma_k=\gamma_k\gamma_0$が$\operatorname{Cl}_{3,0}$の生成元になり$\sigma_1\sigma_2\sigma_3=i$、$\gamma_0D=\partial_0+\sum\sigma_k\partial_k$、$D^2=\partial_0^2-\Delta$（$\operatorname{Cl}_{3,1}$では符号が逆）、時空の2ベクトル$F$で$\gamma_0DF$が$\operatorname{Cl}_{3,0}$の式に戻り$DF=\mu_0cJ$（$J=c\rho\gamma_0+\sum J_k\gamma_k$）となることを確認します。
