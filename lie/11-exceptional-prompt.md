添付は「リー群・リー代数の初歩」シリーズの最終回（第11回）の記事です。前回（参照記事 lie/10）で完成させた分類表に残る例外型$F_4, E_6, E_7, E_8$を、例外型ジョルダン代数$h_3(\mathbb{O})$とフロイデンタールの魔方陣から構成します。$F_4$の構成は$G_2 = \operatorname{Aut}(\mathbb{O})$（参照記事 lie/08）と同じ流儀を踏襲しています。以下の観点でレビューしてください。

- 数式・数学的主張の正しさ。次元・恒等式・分解（ジョルダン恒等式のサイズ依存、$\dim\operatorname{Der}(h_3(\mathbb{O})) = 52$、$52 = 36 + 16 = 28 + 8 + 8 + 8$、$[D, L_X] = L_{D(X)}$、$\mathfrak{e}_6$の閉包と$\det$保存、魔方陣の各成分、$E_7$・$E_8$の次元分解）は数値計算で確認済みなので、検算は不要です。数値で確かめていない次の主張の述べ方を重点的に見てください
    - 「$vv^\dagger$が冪等になるのは3成分が1つの四元数部分代数に収まる場合」（本文・まとめでは「限られ」と必要十分に読める書き方）が、条件の述べ方として正確か
    - $3 \times 3$でジョルダン恒等式が「ムーファン恒等式に支えられて」成立する、$\mathbb{O}P^3$の非存在が$h_4(\mathbb{O})$の破綻と「表裏一体」、という説明が誤解を招かないか
    - 16次元ブロックが$\operatorname{Spin}(9)$のスピノル表現であること、$E_6$の中でトレースも保つ部分群が$F_4$であること、$E_8$の最小表現が随伴表現であること、中心（$E_6$は$\mathbb{Z}_3$、$E_7$は$\mathbb{Z}_2$）、ジョルダン・フォン・ノイマン・ウィグナーの分類とアルバートの定理の述べ方
- 説明の分かりやすさ、論理の飛躍の有無。特に$E_6$の節で「$[L_X, L_Y]$は必ず微分になる」「ケイリー・ハミルトンから$A \circ A^\# = (\det A)I$」を根拠なしに使っている箇所の飛躍の度合い、ティッツの構成で括弧積の定義に立ち入らない断り方が十分か

    - lie/10：分類表の次元、ルート系の扱い、「コンパクト実形」の説明（本文は「10のremで触れた」としているが、lie/10側で実際にremか）、偶然の同型の範囲（本文のrem「2×2が新しいものを生まないわけ」は$\mathfrak{so}(2), \mathfrak{so}(3), \mathfrak{so}(5), \mathfrak{so}(9)$の列を「偶然の同型の列」と呼んでいるが、$\mathfrak{so}(9)$は偶然の同型ではない）、lie/10末尾の「残る4つもすべて八元数と深く結びついている」という記述との対応
