添付は「リー群・リー代数の初歩」シリーズ第7回の記事です。第5回でBCH公式・ヤコビ恒等式・随伴作用を整備し、第6回で$\operatorname{SU}(3)$を構成した流れを受け、結合法則を持たない八元数と単位球面$S^7$を扱い、リー群の装置がどこまで壊れるかを点検します。参照記事は、前提を供給する第5回、八元数の基本事項（三つ組の定義本体）、および十六元数・零因子を扱う後続記事です。以下の観点でレビューしてください。

- 数式・数学的主張の正しさ。特に次を検算してください
    - 八元数の成分計算の符号：$(e_1e_2)e_4 = e_7$と$e_1(e_2e_4) = -e_7$、$[e_2,e_4] = 2e_6$・$[e_4,e_1] = -2e_5$・$[e_1,2e_6] = -4e_7$、結合子$(e_1,e_2,e_4) = 2e_7$。いずれも参照記事のグレイブス＝ケイリーの三つ組の定義と整合しているか
    - ヤコビ恒等式の破れ$J(x,y,z) = -6\,(x,y,z)$の係数と、それが成り立つ範囲（純虚八元数に限るのか、一般の八元数でも成り立つのか）
    - マルツェフ恒等式・ムーファン恒等式の各式の形（引数の並び、括弧の位置）と、「ムーファン恒等式は交代性から導ける」という主張の妥当性
    - $u = \exp(\theta e_1/2)$による共役が3枚の平面$(e_2,e_3), (e_4,e_5), (e_7,e_6)$を回す角度（$\theta$か$2\theta$か）と、平面の組が三つ組の定義と合っているか
    - 「$\{\rho_u\}$の合成が$\operatorname{SO}(7)$の全体を生成する」「単連結コンパクト単純リー群の次元が$3, 8, 10, 14, \dots$」「アダムスの定理」の各記述
- 説明の分かりやすさ、論理の飛躍の有無。「独立な元が何個絡むか」で1元・2元・3元と整理する構成が最後まで一貫しているか、アルティンの定理による正当化が必要な箇所（ループの一意可解性、$\rho_u$の定義、指数写像の全射性）で過不足なく使われているか
- 用語・記法の一貫性。特に参照記事との照合
    - 共役作用の記号：前提知識では$\operatorname{Ad}_g$、本文では$\rho_u$を使い、「群でない$S^7$では$\operatorname{Ad}$が使えない」と断っている。第5回は$\rho_q = \operatorname{Ad}_q$として両者を同一視しているので、この断り方が正確か、記号の揺れとして読まれないか
    - 三つ組・虚数単位・共役・ノルムの記法が八元数の基本事項の記事と一致しているか
    - ケイリー＝ディクソン構成の積公式、零因子の例$(e_1 + e_{10})(e_5 + e_{14}) = 0$の添字規約、モレノの定理の述べ方が、十六元数の記事と食い違っていないか。$S^{15}$を「積で閉じない」と表現することの正確さ（ノルムの乗法性の破れと零因子の出現の区別）
