添付は「リー群・リー代数の初歩」シリーズ第8回の記事で、八元数の自己同型群$G_2$を扱います。前回（参考記事 `lie/07-s7.md`）の八元数・結合子・等傾三重回転を前提とし、別シリーズの量子もつれの記事（参考記事 `hopf/05-entanglement.md`）で扱った複素構造の断面を引き継ぎます。被覆に関する用語は補足記事（参考記事 `lie/double-cover.md`）に由来します。以下の観点でレビューしてください。

- 数式・数学的主張の正しさ
    - 数値検証は済んでいる（微分の次元14、$D_{x,y}$ による張り、$[u,zw]$ の結合子$-3$倍の破れ、$\mathfrak{so}(7) = \mathfrak{g}_2 \oplus \{u \times \cdot\}$、基本三つ組の自由推移性、安定化群の次元14→8→3→0、$e_1$を固定する微分が$\mathfrak{su}(3)$になること、$\theta = 0, \pm 2\pi/3$ と $r^3 \in \mathbb{R}$ の同値）ので、数値で確かめられる部分より**論証の筋**を見てほしい
    - 「純虚である」ことが積だけで特徴付けられるという議論（$x^2$が非正の実数になるのは$x$が純虚のときに限る）と、そこから$\varphi(\operatorname{Im}\mathbb{O}) = \operatorname{Im}\mathbb{O}$を導く手順に飛躍がないか
    - 基本三つ組の定義（$u_3$ が $\operatorname{span}(1, u_1, u_2, u_1u_2)$ に直交）と自由度の数え上げ $6+5+3$ の対応。特に3本目が$S^4$でなく$S^3$になる説明
    - $e_1$を固定する部分群が$\operatorname{SU}(3)$になる議論（$\mathbb{C}$-線形性→ユニタリ性→行列式1）のうち、「乗法の保存が行列式1を強制する」は対角断面しか示していない。この飛躍の断り方が適切か
- 説明の分かりやすさ、論理の飛躍の有無
    - 「八元数の積は非結合的だが写像の合成は結合的」という本記事の中心的な主張が、自己同型群の節とリー代数の節（ヤコビ恒等式の回復）で二重に使われている。重複感がないか、どちらかを削るべきか
    - 結合子が「破れを測る量」から「補正項」へ役割を変える箇所の橋渡し
- 用語・記法の一貫性
    - 三つ組の流儀は参考記事 `lie/07-s7.md` の$(e_1,e_2,e_3),(e_1,e_4,e_5),(e_1,e_7,e_6),(e_2,e_4,e_6),(e_2,e_5,e_7),(e_3,e_4,e_7),(e_3,e_6,e_5)$。本記事の $e_3 = e_1e_2,\ e_5 = e_1e_4,\ e_6 = e_2e_4,\ e_7 = e_3e_4$ がこれと整合するか
    - **特に注意**：複素基底 $e_2, e_4, e_6$ の「$i$倍」を「$e_1e_2 = e_3$など」と書いている箇所が2つある（共役作用の節と$\operatorname{SU}(3)$の節）。この流儀では $e_1e_6 = -e_7$ であり、参考記事 `hopf/05-entanglement.md` はこの符号を明示している。「など」で一般化してよいか、符号への言及が要らないか
    - 参考記事 `hopf/05-entanglement.md` は「$e_1$を固定する自己同型全体が$\operatorname{SU}(3)$」「$G_2$は14次元」をすでに述べている。本記事の書き方が、そちらを引用として扱えているか（同じことを初出のように書いていないか）
    - 「等傾三重回転」「基本三つ組」「微分（derivation）」の表記の揺れ
    - 「被覆の物語がない群」の注意書きは、参考記事 `lie/double-cover.md` を引用して$\operatorname{SO}(3)$の非単連結性・$\operatorname{Spin}(3) \cong \operatorname{Sp}(1)$・$\operatorname{Sp}(1)$の中心$\{\pm 1\}$を並べている。しかし**中心についてはその記事に記述がない**ので、引用の範囲が適切か、中心の話を引用なしで述べるべきかを見てほしい。「単連結」「普遍被覆」「二重被覆」の用語の使い方（本記事は「$2$重に覆われ」、参考記事は主に「二重被覆」）が揃っているかも確認したい
    - $G_2$が単連結かつ中心が自明であること、およびリー代数$\mathfrak{g}_2$を持つ連結コンパクトリー群が同型を除き一意であるという主張は、本記事では証明していない。断り書きなしで述べてよい水準か
- 日本語表現の自然さ
- 構成上の制約

    - `&&&`ブロックの種類（def / thm / fml / rem）の使い分けが内容の性質に合っているか。特に$\operatorname{SO}(7)$の分解と基本三つ組による決定を`thm`にしている点
