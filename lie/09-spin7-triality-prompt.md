添付は「リー群・リー代数の初歩」シリーズ第9回の記事です。前2回（八元数の共役作用と$\operatorname{SO}(7)$、$G_2 = \operatorname{Aut}(\mathbb{O})$）と、別シリーズの八元数の左作用の記事（$\operatorname{Cl}_{0,6}(\mathbb{R}) \cong M_8(\mathbb{R})$、体積要素$L_7$、射影$P$）を前提に、左作用から$\operatorname{Spin}(7)$、$\operatorname{Spin}(8)$と三対性を構成し、$G_2$をスピノル$1$の固定部分群・2つの$\operatorname{Spin}(7)$の交わりとして捉え直します。参照記事として第8回（$G_2$）と八元数の左作用の記事を添付します。以下の観点でレビューしてください。

- 数式・数学的主張の正しさ
    - 成分・次元の主張（生成関係、$L_1 \cdots L_7 = -I$、各固定部分群の次元、射影$a \mapsto a_\pm, a_0$の単射性、1枚回しと等傾4枚回しの対応）は数値で確認済みです。論証の筋道を重点的に見てください
    - 「実部を許すとSO(8)」の注意で、1パラメータ族が$\operatorname{Spin}(7)$にとどまれない理由づけと、「単一の左作用$L_u$も$\operatorname{Spin}(7)$の元」という前節の主張が矛盾なく読めるか
    - 「三対性の原理」の定理の述べ方（リー代数では1対1、群では符号を除いて一意）と、外部自己同型であることの論証（固有値構造の違い）が十分か。$S_3$が外部対称性として「実現される」という主張の根拠が本文で足りているか
    - 「なぜ8次元だけか」の段落で、半スピノルの実次元の列（$n = 4, 6, 8, 10$で$4, 8, 8, 32$）と、$n = 4$を除外する理由が正確か
- 説明の分かりやすさ、論理の飛躍の有無
    - 整合式$g(vz) = \chi_g(v)g(z)$の導出（$x = g(z)$と置き直す部分）と、そこから$G_2$を導く「2色が1色に潰れる」論法が追えるか
    - 2つの$\operatorname{Spin}(7)$の交わりで、$g_0(1) = 1$と$g_-(1) = 1$から$g_+ = g_- = g_0$を導く代入の順序が正しく書けているか
- 用語・記法の一貫性
    - 第8回との照合：$G_2$の定義、$\mathfrak{g}_2 = \operatorname{Der}(\mathbb{O})$、$\operatorname{SU}(3)$の出し方、固定部分群の鎖$14 \to 8 \to 3 \to 0$。第8回は$e_1, e_2, e_4$（基本三つ組）を順に固定しますが、本記事の鎖は$e_7, e_1, e_2$を固定します。基底の違いが読者を混乱させないか、「先の鎖につなげる」という書き方と整合しているか
    - 八元数の左作用の記事との照合：$\operatorname{Cl}_{0,6}$と$\operatorname{Cl}_{0,7}$の符号規約、体積要素$L_7 = L_1 \cdots L_6$、射影$P$の説明（「$L_xP \mapsto e_x$」の書き方を含む）、「作用する代数とスピノルの分離」の引用が参照先の内容と一致しているか
    - 「スピノル」「半スピノル」「等傾回転」「複素構造」の使い方が前提記事と揃っているか
