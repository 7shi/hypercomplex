# 4. 検討した方針案

## 案A: ブロッホベクトルをスピノル・密度行列から切り離す

スピノルやパウリ行列を導入せず、**単位ベクトル$\boldsymbol r$（ブロッホベクトル）を第一級の対象**として量子ビットを定義する。測定は向き$\boldsymbol n$の指定、確率は

$$p_\pm = \frac{1\pm\boldsymbol r\cdot\boldsymbol n}{2}$$

を規則として置く（`hopf/03`では密度行列とトレースから導出しているが、`qi/`では結果を規則として採用する）。

**扱える範囲**

| 概念 | ブロッホベクトルでの言い換え |
|---|---|
| 純粋状態 | 単位ベクトル$\boldsymbol r$（$S^2$上の点） |
| 測定 | 向き$\boldsymbol n$の指定、結果は$\pm$ |
| 確率 | $(1\pm\boldsymbol r\cdot\boldsymbol n)/2$ |
| 測定後の状態 | $\boldsymbol r\to\pm\boldsymbol n$ |
| 混合状態 | $|\boldsymbol r|<1$（球の内部）、最大混合は$\boldsymbol r=0$ |
| 量子ゲート | $\mathrm{SO}(3)$の回転 |
| 相対位相 | 方位角$\varphi$ |
| 大域位相 | そもそも現れない |

**利点** — 大域位相の不定性を毎回断る必要がない。ゲートが$\mathrm{SU}(2)$ではなく$\mathrm{SO}(3)$になるので半角の説明が不要（必要になった時点で`hopf/01`・`lie/02`を参照）。

**限界**

1. 2量子ビット以降、局所ブロッホベクトル2本では状態が決まらず、9成分の相関$\langle\sigma_i\otimes\sigma_j\rangle$が必要。ただしこれは`hopf/06`の「15本の軸」の言葉であり、スタビライザー形式への自然な導入にもなる
2. どの15成分の組が物理的な状態か（正定値性）は幾何だけからは出ない
3. 確率規則$(1+\cos\theta)/2$の根拠は`misc/born-rule.md`・`hopf/03`に委ねることになる
4. **干渉が見えない**。符号（大域位相）を捨てているため、相殺が記述できない

## 案B: 係数を省略した記法から入る

等確率に限れば係数$1/\sqrt2$は情報を持たず、残るのは符号だけ。基底状態を$0,1$、重ね合わせを$0{+}1,\ 0{-}1$と書く。詳細は§7.1を参照。

**利点** — 前提は2進数と中学数学のみ。ドイッチュ、ドイッチュ・ジョサ、グローバー、量子テレポーテーションまで到達できる。干渉（合流・相殺）が計算として明示的に現れる。

**限界** — 任意角度の測定・確率の偏りが扱えない。$S$ゲート（$i$）が扱えないため、クリフォード群は実部分群までしか届かない。

**案Aとの関係** — AとBは互いに逆のものを捨てている。

| | 係数省略表記 | ブロッホベクトル |
|---|---|---|
| 状態 | $0,\ 1,\ 0{\pm}1$ と符号 | $S^2$上の点 |
| 捨てるもの | 大きさ（振幅の比） | 符号（大域位相） |
| 得意 | 干渉・もつれ・回路・アルゴリズム | 測定確率・任意方向・連続的な回転 |
| 苦手 | 任意角度の測定、確率の偏り | 干渉（相殺が見えない） |

係数省略表記の8状態$\{\pm0,\pm1,\pm(0{+}1),\pm(0{-}1)\}$は、実係数で単位円上の45°刻みの8点にあたり、$\theta\to2\theta$の二重被覆で90°刻みの4点に2対1で落ちる。これは$S^3\to S^2$ではなく**実数ホップ写像$S^1\to S^1$（ファイバー$S^0$）**であり、`hopf/04-extension.md`に既述の$H_{\mathbb R}$そのもの。

**この案の致命的な問題** — 既存Qiita記事とほぼ同内容になり、差別化にならない。

## 案C: 実クリフォード代数（幾何代数）で構成する

複素数を使わず、パウリ行列を$C\ell_{3,0}(\mathbb R)$の生成元$e_i$として扱う。

| 標準的な道具 | 幾何代数での姿 |
|---|---|
| 虚数単位$i$ | 2ベクトル$e_1e_2$（回転面）または擬スカラー$I=e_1e_2e_3$ |
| 状態ベクトル$\ket\psi$ | 回転子$\psi$（偶部分代数の元） |
| 密度行列 | $\rho=\frac12(1+\boldsymbol r)$（スカラー＋1ベクトル） |
| トレース | スカラー部$\langle\cdot\rangle_0$ |
| 期待値 | $\langle\rho\,\boldsymbol n\rangle_0$ |
| ユニタリ変換 | 挟み込み$R\rho\tilde R$ |
| 大域位相 | 回転子の右からの作用（＝ホップファイバー） |

**利点**

1. $i$の出所が答えられる。位相の$i$がスピン平面の2ベクトルであり、位相の回転と空間の回転が同一の演算になる
2. 密度行列が幾何的対象になる。$\rho^2=\rho$（純粋性）が$|\boldsymbol r|=1$に直結
3. クリフォードゲート＝正八面体の回転群が、$\boldsymbol n$による鏡映の合成として直接書ける
4. スタビライザーが符号付きブレードの集合として自然

**限界** — 多粒子が難所。$C\ell_3\otimes C\ell_3\neq C\ell_6$であり、$n$量子ビットのテンソル積$(\mathbb C^2)^{\otimes n}$を幾何代数でどう表すかに標準的な答えがない。多粒子時空代数（MSTA、Doran–Lasenby）は各粒子ごとに代数のコピーを用意して擬スカラーを同一視する方式だが記述が重く、文献も少ない。Havel–Doranによる量子情報への適用が先行例としてあるが未調査。

## 案D: 1量子ビットを四元数で書く（現時点で最有力）

案Cと同じ代数を指す（$C\ell_3^+\cong\mathbb H$）が、四元数で書くほうが優れている点が3つある。

**1. テンソル積が破綻しない。** 演算子代数がそのまま

$$M_{2^n}(\mathbb C)\cong\Bigl(\bigotimes^n\mathbb H\Bigr)\otimes_{\mathbb R}\mathbb C$$

となる。$n=1$の場合が双四元数$\mathbb H\otimes\mathbb C\cong M_2(\mathbb C)$、すなわち`qua/01-pauli-qua.md`の到達点そのもの。四元数のテンソル積は`qua/03-qua-tensor.md`で既に扱っている。案Cの多粒子問題を回避できる。

**2. ゲートが単位四元数そのものになる。** $R_{\boldsymbol n}(\theta)=\cos\frac\theta2-\sin\frac\theta2\,\boldsymbol n$ で半角が最初から入り、合成は四元数の積、ブロッホベクトルは$\psi\mathbf k\psi^*$（`hopf/01`）、大域位相は右からの掛け算＝ホップファイバー。行列の指数関数が要らない。

**3. パウリ群が$Q_8$そのものになる。** $\pm1,\pm\mathbf i,\pm\mathbf j,\pm\mathbf k$の8元がそのまま四元数群$Q_8$。`hopf/06`では行列表示を経由した同型として述べているが、四元数で書けば定義から一致する。その正規化群としてのクリフォード群＝正八面体群も同様。

**状態をどこに置くか** — $n=1$では状態も演算子も単位四元数だが、$n\ge2$では状態は$\mathbb C^{2^n}$で$\bigotimes^n\mathbb H$の元ではない。`qua/spinor-ideal.md`の**左イデアル**として状態を取れば、状態と演算子が同じ代数に住み、$n$によらず統一的に書ける。

**限界** — $\mathbb H\otimes_{\mathbb R}\mathbb H\cong M_4(\mathbb R)$なので、$n\ge2$では四元数の構造は行列環に溶ける。四元数表示の利点は$n=1$では本質的（回転そのもの）だが、$n\ge2$では「パウリ群の基底が$\{1,\mathbf i,\mathbf j,\mathbf k\}^{\otimes n}$として見やすい」という水準に落ちる。

## 7.1 「量子コンピューター超入門」（2024年5月）

係数を省略した独自表記による入門。前提は2進数のビット演算と中学数学のみ。

**表記法** — 基底状態$\ket0,\ket1$を`0`, `1`と書き、数値ではなく変数$x,y$のような文字として扱う。重ね合わせ$(\ket0+\ket1)/\sqrt2$を`0+1`、$(\ket0-\ket1)/\sqrt2$を`0-1`と書く。等確率のケースのみを扱うため係数を省略できる。

**ゲート** — $H,X,CX,CCX$の4種のみ。すべて2回の作用で元に戻る。

```
H(0) = 0+1,  H(1) = 0-1
H(0+1) = 0,  H(0-1) = 1
X(0) = 1,    X(1) = 0
```

**項ごとの計算** — 重ね合わせへの作用は項ごとに分配する。$0,1$を$x,y$に置き換えて計算し、係数を取り除いて戻す。

```
H(0+1) = H(0) + H(1) = (0+1)+(0-1) = (0+0)+(1-1) = 0
```

分岐（場合分け）・合流・相殺の過程として解釈でき、合流と相殺を**干渉**と呼ぶ。

**8状態** — $H,X$の組み合わせで得られる状態は次の8つで全部。

- 基底状態: `0, -0, 1, -1`
- 重ね合わせ状態: `0+1, -0-1, 0-1, -0+1`

$0$と$-0$は変数$x$と$-x$のように区別される。測定に符号は影響しない。$HXH$（$Z$ゲート）は`±1`のみ符号反転させる。

**多量子ビット** — ビットを並べて書き、文字式の展開のように分配する。順序を保つ必要があるため$xx=x^2,\ xy=yx$のような変形はできない。$CX$は制御ビットが`1`のとき2番目を反転。もつれは**因数分解できない状態**として現れる（`00+11`は因数分解できないが`00+10 = (0+1)0`はできる）。

**扱った内容** — 重ね合わせによる並列計算（XOR回路、半加算器）、量子もつれの生成・解除、ドイッチュのアルゴリズム、ドイッチュ・ジョサのアルゴリズム、グローバーのアルゴリズム、量子テレポーテーション。検証にはblueqatライブラリ（1.0.4）を使用。

## 7.2 「量子コンピューター超入門2 一般的な表記法」（2024年5月）

簡略化した3点（ケット・テンソル積・係数）を補って一般的な表記法へ書き換える記事。**係数は実数に限定**しており、複素数には踏み込んでいない。

**単位円** — $\ket0,\ket1$の係数を$x,y$とおけば$x^2+y^2=1$で単位円上の点。前記事の8状態は単位円上の45°刻みの8点にあたる。$X$ゲートは$\ket0$と$\ket1$の中点と原点を通る線に対する鏡映、$H$ゲートは$\ket0$と$(\ket0+\ket1)/\sqrt2$の中点と原点を通る線に対する鏡映。

**確率の視覚化** — $(x^2,y^2)$では潰れて情報量が少ないため$(x^2,xy)$を考える。半角・2倍角の公式より

$$(x^2,\ xy)=\left(\frac{1+\cos2\theta}2,\ \frac{\sin2\theta}2\right)$$

となり、**半径$1/2$の円**を描く。元の円の1周が2周になるため、量子状態における符号の違いが区別されなくなる。$x$座標は2乗によりマイナスが消え、確率を直接表す。

**リポジトリとの接続** — この$(x^2,xy)$は、`hopf/04-extension.md`の実数ホップ写像

$$H_{\mathbb R}(\alpha,\beta)=(2\alpha\beta,\ \alpha^2-\beta^2)$$

と、成分の呼び方と$\frac{1+\cdot}2$のずらしを除いて一致する。そのずらしは密度行列$\rho=\frac{1+\boldsymbol r\cdot\boldsymbol\sigma}2$の単位行列成分にあたる。「半径1/2の円」になる理由が、$S^1\to S^1$の二重被覆と密度行列の両方から説明できる。

**未回収の予告が2つある**

1. 「この座標は外積（ベクトル積とは別の演算）で正当化できます。詳細は機会を改めます」→ 幾何代数の道具（`vec-oct/geometric-product-exp.md`、回転子の挟み込み）で回収可能
2. 「複素数に拡張すれば単位超球面上の点となりますが、詳細は機会を改める予定です」→ `hopf/`シリーズ全体がその答え

**続編が未執筆の理由** — 実数から複素数へ拡張すると$S^3\to S^2$になり、四元数による共役作用・パウリ行列・密度行列が必要になる。簡略化できないため書けていない。**本リポジトリには既にその道具が揃っており、`qi/`はこの続きを書ける立場にある。**

## 7.3 「量子力学の非局所性を計算で確認してみた」（2020年2月）

物理の知識を前提とせず、プログラムで非局所性を確認する記事。

**スピン** — 粒子が「特定の方向を向いている」と単純化。ある方向を指定して測定でき、結果は真偽。測定するとスピンはその方向を向く（同じ測定を繰り返せば同じ結果）。横向きの状態で縦方向に測定すると確率$1/2$でランダム。

**確率** — スピン方向と測定方向の角度差$\theta$から

$$\frac{1+\cos\theta}2=\cos^2\frac\theta2$$

直径1（半径$1/2$）の円で図示する。スピン方向の円周上の点から$x$軸に垂線を下ろし、円の左端から交点までの長さが確率。**半径$1/2$の円が7.2と共通**である点に注意。

**CHSH実験** — 左右の粒子の測定角度を$a,a'$と$b,b'$からランダムに選ぶ。

$$S=E(a,b)-E(a,b')+E(a',b)+E(a',b'),\qquad E=\frac{\text{一致した個数}-\text{一致しない個数}}{\text{個数の合計}}$$

局所モデル（崩壊時に乱数を共有するのみ）では$|S|\le2$に収まるが、非局所モデル（測定値2の確率が角度差$\theta_2-\theta_1$に依存する）では破る。ベル・テスト角は$a=0°,\ a'=45°,\ b=22.5°,\ b'=67.5°$。

**エンタングルメントと情報** — $S$に現れるのは両者の測定値の関係であり、片方だけを見れば確率は常に$1/2$。両方を比較しなければ検出できないため、エンタングルメントで情報は送れない。
