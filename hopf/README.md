# ホップファイブレーション

## その他の記事

- [複素2次元ベクトルから2次元球面への射影](c2-to-s2.md) — 正規化された複素数のペアの全体位相を同一視し、位相不変な2次の組み合わせから単位球面に載る座標を定めることで、ホップ写像の式を初等的に導きます。球面全体を覆うことと、同じ点に写るペアが全体位相だけ異なることも確認します。
- [同次座標とホップファイブレーション](homogeneous.md) — 3次元球面上の実4次元座標を複素数のペアの比（同次座標）に変換し、立体射影によって2次元球面へ写す計算を通じてホップファイブレーションを構成します。
- [一般次元における球座標系のバリエーション](spherical-coords.md) — 単位ベクトルの成分を三角関数でどうパターン分けするかによって、一般次元の球座標系に複数のバリエーションが生じることを示し、4次元・6次元の例として量子情報における状態ベクトルを紹介します。

## 四元数とホップファイブレーション

1. [四元数からの生成](01-quaternion.md) - Wikipediaで説明されている四元数からの生成方法を確認します。
2. [スピノルのテンソル積](02-spinor-tensor.md) — 回転子の成分を具体的に計算し、位相差が内積・外積に対応することを確認します。状態ベクトルとパウリ行列によるブロッホベクトルの導出、テンソル積から密度行列が得られることも見ます。
3. [ブロッホ球と密度行列](03-bloch-density.md) — パウリ行列を基底として純粋状態・混合状態を密度行列で表し、混合と重ね合わせの違い、測定の期待値との関係まで見ます。
4. [四元数・八元数への拡張](04-extension.md) — 複素数によるホップファイブレーションを四元数$S^7\to S^4$・八元数$S^{15}\to S^8$に拡大し、対応する写像を構成します。非結合性がどこで効くかを確認します。
5. [2・3量子ビットのもつれとホップファイブレーション](05-entanglement.md) — 2量子ビットの状態空間$S^7$と$H_{\mathbb{H}}$、3量子ビットの$S^{15}$と$H_{\mathbb{O}}$を対応させ、分離可能性がホップ像の成分の消失と同値であることを示します。ファイバーが残りの量子ビットの状態空間に対応すること、複素構造を固定する八元数の自己同型群として$\operatorname{SU}(3)$が現れることも確認します。
6. [量子ゲートを回転子として読み直す](06-clifford-gates.md) — 1量子ビットゲートを位相×回転子に分解し、パウリ群の正規化群としてクリフォードゲートを導入します。位相を除けば正八面体の回転群と一致すること、CNOTによるもつれの生成が軸の行き先から読めることを確認します。
7. [実振幅の量子ビットと実数ホップファイブレーション](07-real-qubit.md) — 状態ベクトルの成分を実数に制限し、実数ホップ写像$S^0\hookrightarrow S^1\to S^1$の全空間・底空間・ファイバーとして量子ビットを読み直します。干渉・もつれ・CHSH不等式の破れ・計算能力までは実振幅で到達し、パウリ群が$D_4$になること、局所トモグラフィーが破れることを確認します。
