# K理論と指数定理

クリフォード代数の分類表に現れる周期性を出発点に、球面上のベクトル場・ベクトル束とディラック作用素の指数を扱う記事シリーズです（全8回、準備中）。

## 記事

1. K理論の見通し（`01-overview.md`）：各点にベクトル空間を連続に並べたベクトル束を、直和で足し、自明束を足して一致するものを同一視し、差を許して群にしたものがK群です。メビウスの帯・球面の接束・ホップ束を例にこの流れを見渡し、円周上ではメビウスの帯が位数2の元になることを確かめます。球面のK群が8周期（複素では2周期）で繰り返すボット周期性と、クリフォード代数の分類表との対応、作用素の指数がK群の元として現れることを、主張として紹介します。
2. 球面上のベクトル場とクリフォード加群（`02-vector-fields.md`）：$\mathbb R^n$がクリフォード代数$\operatorname{Cl}_{0,k}(\mathbb R)$の加群なら、生成元を左から掛ける写像が球面$S^{n-1}$上の正規直交な接ベクトル場を$k$本与えることを示します。分類表から既約加群の次元を読んでラドン＝フルヴィッツ数を求め、数体系の次元が$1,2,4,8$に限られること（フルヴィッツの定理の次元の部分）を導きます。
3. 貼り合わせ関数とホップ束（`03-clutching.md`）：球面上のベクトル束を赤道での貼り合わせ関数で構成し、$S^2$上の複素直線束が回転数で分類されること、ホップ束がその基本例であることを示します。四元数・八元数のホップ束も同じ形で与えます。
4. K群とボット周期性（`04-bott.md`）：球面のK群を貼り合わせ関数の安定なホモトピー類として計算し、クリフォード加群の貼り合わせ関数から生成元を構成します。分類表から実K群の8周期の表を計算し、ボット周期性定理との対応を確かめます。
5. フレドホルム指数とテプリッツ作用素（`05-fredholm.md`）：核と余核の次元の差としての指数を導入し、有限次元では常に次元の差で決まることと、片側シフトやテプリッツ作用素では回転数が指数を与えることを対比します。
6. 球面上のディラック作用素（`06-sphere-dirac.md`）：平坦なディラック作用素を球面の方向に分解して球面上の作用素を取り出し、球面モノジェニックスから固有値を求めます。リヒネロビッチの公式により核が消えることを示します。
7. ホップ束で捩ったディラック作用素（`07-twisted.md`）：$S^2$上のディラック作用素をホップ束の冪で捩ると、核が同次多項式の空間として現れ、その次元が貼り合わせ関数の回転数に一致することを計算します。
8. アティヤ＝シンガーの指数定理（`08-atiyah-singer.md`）：主表象が球面のK群の生成元と同じ写像であることから位相的指数を定め、指数定理の主張を述べます。ガウス＝ボネの定理などへの特殊化をまとめます。

検討の経緯は[MEMO.md](MEMO.md)にまとめています。

## 構想

[クリフォード代数の構造と表現](../clif/01-representation.md)では、実クリフォード代数の型が8周期で、複素クリフォード代数の型が2周期で繰り返すことを示し、K理論のボット周期性定理と対応することに触れるに留めました。本シリーズは、この対応の具体的な中身を球面に限って確かめます。

シリーズの軸は、ベクトル$\boldsymbol x$をクリフォード積で掛ける写像$\boldsymbol x\mapsto\boldsymbol x\cdot$です。この写像は、球面上の接ベクトル場を与え、球面上のベクトル束を貼り合わせる関数となってK群の生成元を与え、ディラック作用素の主表象にもなります。$2,4,8$次元の場合が複素数・四元数・八元数のホップ束にあたり、数体系が$1,2,4,8$次元で打ち止めになることと8周期性が、位相の側から説明されます。

指数は、作用素の核と余核の次元の差です。有限次元では常に次元の差で決まってしまう量が、無限次元では作用素の位相的な性質を反映することを、テプリッツ作用素と回転数から見ます。球面上のディラック作用素は、[クリフォード解析](../clif-analysis/README.md)の平坦なディラック作用素を球面の方向に分解して取り出し、ホップ束で捩ったときの核の次元がチャーン数に一致することを計算します。

ボット周期性定理、ベクトル場の本数の上界（アダムスの定理）、アティヤ＝シンガーの指数定理は主張と具体例での検証に留め、証明は扱いません。一般の多様体上のベクトル束の理論にも立ち入りません。
