# K理論と指数定理

クリフォード代数の分類表に現れる周期性を出発点に、球面上のベクトル場・ベクトル束とディラック作用素の指数を扱う記事シリーズです（全8回、準備中）。

## 記事

1. [K理論の見通し](01-overview.md)：各点にベクトル空間を連続に並べたベクトル束を、直和で足し、自明束を足して一致するものを同一視し、差を許して群にしたものがK群です。メビウスの帯・球面の接束・ホップ束を例にこの流れを見渡し、円周上ではメビウスの帯が位数2の元になることを確かめます。球面のK群が8周期（複素では2周期）で繰り返すボット周期性と、クリフォード代数の分類表との対応、作用素の指数がK群の元として現れることを、主張として紹介します。
2. [球面上のベクトル場とクリフォード加群](02-vector-fields.md)：$\mathbb R^n$がクリフォード代数$\operatorname{Cl}_{0,k}(\mathbb R)$の加群なら、生成元を左から掛ける写像が球面$S^{n-1}$上の正規直交な接ベクトル場を$k$本与え、逆に1次式で与えられる正規直交な接ベクトル場はクリフォード代数の作用を定めることを示します。分類表から既約加群の次元を読んでラドン＝フルヴィッツ数を求め、平行化可能な球面が$S^0,S^1,S^3,S^7$に限られることと、ノルムの乗法性を持つ数体系の次元が$1,2,4,8$に限られること（フルヴィッツの定理の次元の部分）を導きます。
3. [貼り合わせ関数とホップ束](03-clutching.md)：球面上のベクトル束を赤道での貼り合わせ関数で表し、ホモトピックな貼り合わせ関数が同型な束を与えることを示します。$S^2$上の複素直線束が回転数で分類されることを示し、接束の回転数から$S^2$の毛玉の定理を導きます。実数・複素数・四元数・八元数のホップ束の貼り合わせ関数が、単位数を左から掛ける写像であることを示します。
4. [K群とボット周期性](04-bott.md)：球面の複素K群の元を貼り合わせ関数の安定なホモトピー類として表し、平面の回転によってK群の和が貼り合わせ関数の積にあたることを示します。$S^2$では$H\oplus H\cong H^2\oplus\underline{\mathbb C}$を回転で示し、行列式の回転数から$\tilde K(S^2)\cong\mathbb Z$を導きます（$\operatorname{SL}(n,\mathbb C)$の単連結性は主張として使用）。$\operatorname{Cl}_{0,k-1}(\mathbb R)$の加群の上のパラベクトルを貼り合わせ関数とし、1つ多い生成元まで延長できる加群が自明な束を与えることを示したうえで、加群の群を制限の像で割った群を分類表から計算して$\mathbb Z_2,\mathbb Z_2,0,\mathbb Z,0,0,0,\mathbb Z$を得ます。アティヤ＝ボット＝シャピロの定理とボット周期性定理は主張に留めます。
5. [フレドホルム指数とテプリッツ作用素](05-fredholm.md)：片側のずらしとその有限の切断を比べ、指数が列の端から生じることを見ます。作用素の積の指数が指数の和になることと、有限階数の摂動で指数が変わらないことを示し、記号が$z$の正負の冪の有限和であるテプリッツ作用素について、記号を1次式に分解して指数が記号の回転数の符号を反転したものに等しいことを示します。連続な記号の場合は、フレドホルム性と連続変形での不変性を認めて導きます。記号を$S^2$上の直線束の貼り合わせ関数と見ると、指数は$\tilde K(S^2)$の生成元$[H]-1$に$-1$を対応させます。
6. [球面上のディラック作用素](06-sphere-dirac.md)：平坦なディラック作用素を$\boldsymbol xD=E+Γ$と動径方向と球面方向に分け、接ベクトルの掛け算$X\boldsymbol x$とそれと両立する共変微分から、球面$S^{n-1}$上のディラック作用素$\frac{n-1}2-Γ$を取り出します。球面モノジェニックスから固有値$\pm(k+\frac{n-1}2)$を求め、$S^1$と$S^2$で動く枠に移した形（スピン接続の項$\frac{\cotθ}2$と成分の反周期性）と比べます。リヒネロビッチの公式を示し、$n\ge3$で核が消えることを導きます（標準的なスピン接続との一致は一般の$n$では主張として使用）。

## 予定
7. ホップ束で捩ったディラック作用素（`07-twisted.md`）：$S^2$上のディラック作用素をホップ束の冪で捩ると、核が同次多項式の空間として現れ、その次元が貼り合わせ関数の回転数に一致することを計算します。
8. アティヤ＝シンガーの指数定理（`08-atiyah-singer.md`）：主表象が球面のK群の生成元と同じ写像であることから位相的指数を定め、指数定理の主張を述べます。ガウス＝ボネの定理などへの特殊化をまとめます。

## 構想

[クリフォード代数の構造と表現](../clif/01-representation.md)では、実クリフォード代数の型が8周期で、複素クリフォード代数の型が2周期で繰り返すことを示し、K理論のボット周期性定理と対応することに触れるに留めました。本シリーズは、この対応の具体的な中身を球面に限って確かめます。

シリーズの軸は、ベクトル$\boldsymbol x$をクリフォード積で掛ける写像$\boldsymbol x\mapsto\boldsymbol x\cdot$です。この写像は、球面上の接ベクトル場を与え、球面上のベクトル束を貼り合わせる関数となってK群の生成元を与え、ディラック作用素の主表象にもなります。$2,4,8$次元の場合が複素数・四元数・八元数のホップ束にあたり、数体系が$1,2,4,8$次元で打ち止めになることと8周期性が、位相の側から説明されます。

指数は、作用素の核と余核の次元の差です。有限次元では常に次元の差で決まってしまう量が、無限次元では作用素の位相的な性質を反映することを、テプリッツ作用素と回転数から見ます。球面上のディラック作用素は、[クリフォード解析](../clif-analysis/README.md)の平坦なディラック作用素を球面の方向に分解して取り出し、ホップ束で捩ったときの核の次元がチャーン数に一致することを計算します。

ボット周期性定理、ベクトル場の本数の上界（アダムスの定理）、アティヤ＝シンガーの指数定理は主張と具体例での検証に留め、証明は扱いません。一般の多様体上のベクトル束の理論にも立ち入りません。
