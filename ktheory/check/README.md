# 検証コード

K理論と指数定理の記事の数式を検証するPythonスクリプトです。プロジェクトルートで `uv sync` により環境を構築し、`uv run ktheory/check/<ファイル名>` で実行します。八元数の積は`common.octonion`（`src/common/octonion.py`）を使います。

- [01-overview.py](01-overview.py)：01-overview.mdの数式。メビウスの帯2枚の貼り合わせ$-I_2$が回転で$I_2$に変形できること、自明束を足しても貼り合わせ行列の行列式の符号が残ること（$M-1\ne0$）、$\mathbb C^\times$の中で$-1$が$1$につながること、実数・複素数・四元数・八元数の単位数を掛ける貼り合わせ関数が可逆で、虚部の1次結合の2乗が$-|\boldsymbol x|^2$になることを確認します。
- [02-vector-fields.py](02-vector-fields.py)：02-vector-fields.mdの数式。$\operatorname{Cl}_{0,k}(\mathbb R)$（$k=1,\dots,8$）の実行列表現を複素数・四元数・八元数の左からの積と倍加で作り、生成元が反対称な直交行列でクリフォード関係を満たすこと、表現空間の次元が既約加群の次元$a_k=2,4,4,8,8,8,8,16$に一致すること、可換子環の次元（$\mathbb C,\mathbb H,\mathbb R$の型）と像の次元（$k=3,7$で擬スカラーがスカラーになる直和型）を確認します。$\boldsymbol x\mapsto e_i\boldsymbol x$が正規直交な接ベクトル場になること、逆に1次式の正規直交な接ベクトル場が偏極でクリフォード関係を与えること、ラドン＝フルヴィッツ数$\rho(n)$の2通りの計算の一致、$\rho(n)=n$と$a_{n-1}\mid n$がともに$n=1,2,4,8$に限られること、八元数で$L_1\cdots L_6=L_7$となることも確認します。
- [03-clutching.py](03-clutching.py)：03-clutching.mdの数式。実数・複素数・四元数・八元数のホップ束のファイバーが$(1-r)α=cβ$で与えられ、赤道で貼り合わせが$μ=L_cλ$になること、複素数で01の$μ=zλ$と一致し$|z|<1$が南半球であること、hopf/04-extension.mdの規約$2α^*β$が共役で同じ底の点に写り、貼り合わせ$R_{c^*}$が共役で$L_c$に戻ることを確認します。回転数の加法性・摂動での不変性・回転数0での連続な対数、接束の$v^w=-z^{-2}v^z$（回転数$-2$）と北極の2次の零点、$L_c1=c$、行列式の回転数も確認します。
- [04-bott.py](04-bott.py)：04-bott.mdの数式。平面の回転による$\operatorname{diag}(a,b)\simeq\operatorname{diag}(ab,1)$（$H\oplus H\cong H^2\oplus\underline{\mathbb C}$、$H\oplus H^{-1}$が自明）と行列式の回転数の保存、延長できる加群で$\cos t\,g_W+\sin t\,J_k$が直交行列になることを確認します。$\operatorname{Cl}_{0,k}(\mathbb R)$の既約加群を$\operatorname{Cl}_{0,k-1}(\mathbb R)$に制限したときの個数（直和型では擬スカラーの符号で区別）と、その余核が$\mathbb Z_2,\mathbb Z_2,0,\mathbb Z,0,0,0,\mathbb Z$になること、複素では$0,\mathbb Z$の繰り返しで$\operatorname{Cl}_1(\mathbb C)$の2つの既約加群が回転数$\pm1$の貼り合わせ関数を与えること、$2\mathbb H$のもう1つの既約加群が$L_{c^*}$を与えること、$\operatorname{Cl}_{0,k+8}$が$\mathbb R^{16a_k}$に作用することも確認します。
