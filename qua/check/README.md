プロジェクトルートで `uv sync` により環境を構築し、`uv run qua/check/<ファイル名>` で実行します。

- [02-nonion.py](02-nonion.py) — 02-nonion.md の数式の数値検証。$2$次の具体例（$u^2=v^2=-I$、$uv=-vu$、行列式$z^2+y^2+x^2$、行列単位との対応と$-\mu+\nu=-v$の符号）、$3$次の生成元の$u^3=v^3=I$・$vu=\rho uv$（$\rho^2$ではない）・行列式$z^3+y^3+x^3$、$u,v$の入れ替えで行列式が不変で$\rho$が$\rho^2$に変わること、$9$個の基底行列の表との一致、$\rho^2uv$のシフト行列、位数$27$の群、行列式だけでは交換関係が従わない反例、$uv=\rho S,\ vu=\rho^2S$、$i=-v,\ j=u,\ k=uv$での$ij=k$を確認します。
- [03-qua-tensor.py](03-qua-tensor.py) — 03-qua-tensor.md の数式の数値検証。$\mathbb H,\mathbb H'$の左正則表現（$\mathbb H'$で$k^2=1$）、$\mathbb H\otimes\mathbb H$の互いに反交換する極大な組が3個（20組）と5個（6組）に分かれ、5個の組が(1)〜(6)と一致すること、(3)の任意の4元が残りの1元と全基底を生成する式、選んだ生成元の符号数$(2,2)$、$\mathbb H'\otimes\mathbb H'$の4通りの符号数$(3,1),(2,2),(2,2),(3,1)$、$\otimes\mathbb H,\otimes\mathbb H'$の拡張公式（複数の基底での符号数の変化）、$\mathbb H'\otimes\mathbb H$と$\mathbb H\otimes\mathbb H'$の符号数を確認します。
- [04-4d-bsqua.py](04-4d-bsqua.py) — 04-4d-bsqua.md の数式の数値検証。体積要素$\Omega$による2ベクトルの対と冪等元$\dfrac{1\pm\Omega}2$による$\mathbb H\oplus\mathbb H$分解、対角表現の成分ごとの積と$T$の準同型性、等傾回転の合成による二重回転（$e^{\alpha i}qe^{\beta i}$の2平面の回転角$\alpha\pm\beta$）、正規形・一般の回転面での$r_L\,q\,r_R$とクリフォード代数の回転の一致、直和成分の対$(r_R,r_L^{-1})$の成分ごとの積と回転子の積の合成則$(s_Lr_L,\ r_Rs_R)$、$L_uR_v$が張る$M_4(\mathbb R)\cong\operatorname{Cl}_{3,1}(\mathbb R)$、テンソル積での符号の相殺（2対1対応の核）、偶部分代数の階梯を確認します。
- [05-dual-qua.py](05-dual-qua.py) — 05-dual-qua.md の数式の数値検証。二重数の演算と$f(x+\varepsilon y)=f(x)+\varepsilon y f'(x)$、3種の共役と二重数値ノルム、剛体変換のサンドイッチ公式と$\mathrm{SE}(3)$の合成則（通常の共役では並進が消える負のチェックを含む）、単位二重四元数の分解$\sigma=(1+\frac\varepsilon2 t)r$と作用の核$\{\pm1\}$、接平面モデル（$\varepsilon$倍角の回転子による並進と基点を通る軸の回転）、ねじ運動の指数表示とねじ軸の抽出、$\operatorname{Cl}_{3,0,1}^0(\mathbb R)$との同型（全$64$積）、擬スカラーの三分法を確認します。
- [06-slerp.py](06-slerp.py) — 06-slerp.md の数式の数値検証。対数写像と冪の指数法則、なす角と半角関係、大円弧の等速性と最短性、冪形式とsin重み形式の一致（外挿を含む）、左右不変性と対称性、世界座標軸と角速度の一定性、符号選択と2本の経路（中間の姿勢が異なる負のチェック）、NLERPの不等速性、$\operatorname{Cl}_{3,0}^0(\mathbb R)$・$\operatorname{Cl}_{4,0}(\mathbb R)$での回転子の補間（線形結合が回転子にならない負のチェック）、ScLERPの端点・実部・軸上の並進、退化の数値安定性を確認します。
- [spinor-ideal-lxryp.py](spinor-ideal-lxryp.py) — spinor-ideal.md の射影による積の抽出の数値検証。$R_yP=L_yP$、16個の基底すべてでの$L_uR_vP\mapsto uv$（四元数の乗積表との一致）、一般の四元数への線形拡張、結合律による$L_xR_yP=L_{xy}P$への還元を確認します。
- [spinor-ideal-cl31.py](spinor-ideal-cl31.py) — spinor-ideal.md のクリフォード代数構造と射影・復元の数値検証。積の規則$L_uL_v=L_{uv},R_uR_v=R_{vu},L_uR_v=R_vL_u$、16個の$L_uR_v$の一次独立性、自乗が$-I$の6個と$+I$の9個、互いに反交換する最大の組（5個）と記事が挙げた組の自乗$(+,+,+,-,-)$、生成元$e_1,\dots,e_4$の計量と体積要素$\omega=-R_k$、グレード別基底の表、$P=\frac14(I-L_iR_i-L_jR_j-L_kR_k)$と実部抽出$\frac14(x-ixi-jxj-kxk)=x_0$、復元式$L_x=\sum_uR_u(L_xP)R_u^{-1}$（各項が$L_x$の1列であること）を確認します。さらに、任意の$A$について$AP=L_{A(1)}P$で和が$L_{A(1)}$を返すこと（復元先が左作用に限られること）、5個の組の積$f_1\cdots f_5=I$（$\operatorname{Cl}_{3,2}(\mathbb R)$の表現が忠実でないこと）、八元数側との対比（$L_xL_yP=L_{xy}P$は成り立つが演算子としては$L_xL_y\ne L_{xy}$、および$L_1,\dots,L_6$の64単項式のランクが64で左作用だけで$M_8(\mathbb R)$を生成すること）、証明で使う$L_xP=\boldsymbol x c_1^T$・$c_1^TR_u^{-1}=c_u^T$も確認します。
- [history.py](history.py) — history.md の数式の検証。ハミルトンの関係式と導かれる積、純虚四元数の積$-\boldsymbol p\cdot\boldsymbol q+\boldsymbol p\times\boldsymbol q$・平方・$qq^*$、ナブラの平方が負のラプラシアンになること、対称部分・反対称部分による内積とベクトル積の分離、単位四元数の挟み込みとロドリゲスの公式の一致（単位でない$q$で拡大が入る負のチェック）、パウリ行列が$\sigma_a^2=I$で、$-\mathrm i\sigma_a$への対応が関係式を満たし準同型になること、$\operatorname{Cl}_{3,0}(\mathbb R)$でのベクトルの平方の正値性・幾何積の分解・2ベクトルと四元数の対応・回転子の挟み込みと$q\boldsymbol vq^*$の一致、$\operatorname{Cl}_{0,2}(\mathbb R)$のグレード1の生成元、$x\mapsto axb^{-1}$が$\mathrm{SO}(4)$に入ること、座標平面の数と次元が一致するのは3次元だけであること、擬ベクトルの変換則$(Q\boldsymbol p)\times(Q\boldsymbol q)=\det(Q)\,Q(\boldsymbol p\times\boldsymbol q)$を確認します。
