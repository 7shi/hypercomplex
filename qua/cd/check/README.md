# 検証コード

プロジェクトルートで `uv sync` により環境を構築し、`uv run qua/cd/check/<ファイル名>` で実行します。

- [bcmp-qua.py](bcmp-qua.py) — bcmp-qua.md の数式の数値検証。複素数の共役積の対称性、双複素数と四元数の積公式・結合法則・追い越し規則、行列表現が積を保つことと$M(p)v(q)=v(pq)$、行列式、共役とエルミート共役の対応、四元数の共役積（4次元の内積と反対称な虚部、$(pq)^*=q^*p^*$）、双複素数の共役積（$k$成分が対称に残ること）と零因子、基底とパウリ行列の対応を確認します。
- [cd-to-matrix.py](cd-to-matrix.py) — cd-to-matrix.md の数式の数値検証。$jp=p^*j$、四元数の積とケイリー＝ディクソンの構成法の一致、素朴な行列 $\begin{pmatrix}p&-q\\q&p\end{pmatrix}$ では一致しないこと、行列とベクトルの計算 $M(p,q)v(r,s)=v(pr-qs^*,ps+qr^*)$、ベクトルが行列の第1列であること、行列の積が四元数の積を保つこと、$a,b,c,d$ で展開した行列が heuristic-cmatrix.md の行列と一致することを確認します。
- [heuristic-cmatrix.py](heuristic-cmatrix.py) — heuristic-cmatrix.md の数式の数値検証。$i,j,k$ の左乗算の成分、単純な対応で $i$ は対角行列で表せるが $j$ の左乗算は複素線形でないこと、ひねりを加えた表現での $M_I,M_J,M_K$ の作用と乗算規則、線形結合の成分と第1列がベクトル表現に一致すること、一般の四元数での $M(x)v(y)=v(xy)$ と $M(x)M(y)=M(xy)$、$I_H,J_H,K_H$ の組み替えと乗算規則、$i$ を掛けてパウリ行列が得られることを確認します。
- [matrix-to-pauli.py](matrix-to-pauli.py) — matrix-to-pauli.md の数式の数値検証。$J_H$ の作用、$J_H$ と反交換する行列の形と2乗、パラメータ表示の $I_H,K_H$ が四元数の乗算規則を満たすこと・別のパラメータ表示が $θ$ のずれであること、$θ=π$ での成分、転置・共役・エルミート共役での符号、$4\times4$ 実行列表現の転置がエルミート共役に対応すること、パウリ行列の成分・2乗・エルミート性と積の関係（$θ=0$ では $iI_H=-σ_1$ になること）、$σ_1σ_2σ_3=iI$ と双四元数の一般形を確認します。
- [real-to-cmatrix.py](real-to-cmatrix.py) — real-to-cmatrix.md の数式の数値検証。$i,j,k$ の左乗算の成分と $4\times4$ 実行列 $M_i,M_j,M_k$、$(a,b,c,d)$ の並びでは $M_i$ だけが複素行列に変換できること、24通りの並べ替えのうち12通りが変換でき一覧が記事と一致すること、$(d,a,b,c)$ での $M_i',M_j',M_k'$ と $I_H,J_H,K_H$ の成分・作用・乗算規則、ベクトルの $-i$ 倍が線形結合の第1列に一致すること、一般の四元数の積を保つこと、パウリ行列との対応を確認します。
