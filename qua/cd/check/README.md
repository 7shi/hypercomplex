# 検証コード

プロジェクトルートで `uv sync` により環境を構築し、`uv run qua/cd/check/<ファイル名>` で実行します。

- [bcmp-qua.py](bcmp-qua.py) — bcmp-qua.md の数式の数値検証。複素数の共役積の対称性、双複素数と四元数の積公式・結合法則・追い越し規則、行列表現が積を保つことと$M(p)v(q)=v(pq)$、行列式、共役とエルミート共役の対応、四元数の共役積（4次元の内積と反対称な虚部、$(pq)^*=q^*p^*$）、双複素数の共役積（$k$成分が対称に残ること）と零因子、基底とパウリ行列の対応を確認します。
- [cd-to-matrix.py](cd-to-matrix.py) — cd-to-matrix.md の数式の数値検証。$jp=p^*j$、四元数の積とケイリー＝ディクソンの構成法の一致、素朴な行列 $\begin{pmatrix}p&-q\\q&p\end{pmatrix}$ では一致しないこと、行列とベクトルの計算 $M(p,q)v(r,s)=v(pr-qs^*,ps+qr^*)$、ベクトルが行列の第1列であること、行列の積が四元数の積を保つこと、$a,b,c,d$ で展開した行列が heuristic-cmatrix.md の行列と一致することを確認します。
