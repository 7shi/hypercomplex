# 検証コード

プロジェクトルートで `uv run lebesgue/check/<ファイル名>` により実行します。

- [01-measure-integral.py](01-measure-integral.py) — 01-measure-integral.md の数式の数値検証。ディリクレ関数のリーマン和の不一致、$\varepsilon/2^n$被覆の等比級数、単関数近似の単調収束（$x^2$の積分$1/3$）、極限と積分が交換できない関数列$n\,\mathbb{1}_{(0,1/n)}$と優関数の非存在、sophomore's dreamの項別積分を確認します。
- [02-l2-hilbert.py](02-l2-hilbert.py) — 02-l2-hilbert.md の数式の数値検証。ランプ関数列が$L^2$のコーシー列なのに極限が階段関数となる完備性の破れ、$\varepsilon/2^n$被覆で有理数を太らせた稠密で測度の小さい開集合、平行四辺形の法則（$L^2$で成立・$L^1$で不成立）、三角関数系の正規直交性、$f(x)=x$のフーリエ係数とベッセル・パーセバル、フーリエ部分和の最良近似性、バーゼル問題$\sum 1/n^2 = \pi^2/6$を確認します。
- [03-probability.py](03-probability.py) — 03-probability.md の数式の数値検証。二進展開の桁がコイン投げとして振る舞うこと（各桁の確率$1/2$・独立性・大数の法則）、ルベーグ＝スティルチェス積分による離散・連続・混合分布の期待値の統一、ラドン＝ニコディムの密度、条件付き期待値の直交性・最良予測性・タワー則、全経路の列挙による$S_n$と$S_n^2-n$のマルチンゲール性とマルチンゲール変換の公平性、破産問題$b/(a+b)$と$E[T]=ab$、倍賭け法の期待値が厳密に$0$であることを確認します。
- [04-brownian-ito.py](04-brownian-ito.py) — 04-brownian-ito.md の数式の数値検証。ランダムウォークのスケーリング極限の正規性、増分の分散と独立性、2次変分$\sum(\Delta B)^2 \to t$（$L^2$誤差$2t^2/n$）と全変動の発散、伊藤の等長性、評価点による値の違い（左端で$(B_T^2-T)/2$・中点で$B_T^2/2$）、伊藤積分の期待値$0$、$f(x)=x^4$に対する伊藤の補題の経路ごとの成立、幾何ブラウン運動のオイラー丸山法と厳密解の一致、モーメント$E[B_t^4]=3t^2$・$E[B_t^6]=15t^3$を確認します。
- [05-black-scholes.py](05-black-scholes.py) — 05-black-scholes.md の数式の数値検証。幾何ブラウン運動の平均$S_0 e^{\mu T}$、リスク中立モンテカルロとブラック＝ショールズ公式の一致、実測度モンテカルロの$\mu$依存とBS価格からのずれ、ドレアン指数によるギルサノフ重み付けで実測度経路からBS価格を回収することと$\mu$非依存性、コールのデルタ$N(d_1)$、離散デルタヘッジの複製誤差が分割細分で縮小することを確認します。
- [06-nelson-stochastic-qm.py](06-nelson-stochastic-qm.py) — 06-nelson-stochastic-qm.md の数式の数値検証。原点出発ブラウン運動の前進・後退微分（回帰係数$0$と$h/t$）、広がるガウス密度の浸透速度$-x/(2t)$と連続の式、調和振動子基底状態の量子ポテンシャル$U_Q + V = \frac12\hbar\omega$、浸透速度$u = \nu(\log\rho)_x = -\omega x$、定常フォッカー＝プランク流$J = 0$、ネルソン定常則$uu'+\nu u''=\omega^2 x$、対応するOU過程の不変分散$\hbar/(2m\omega)$とヒストグラムの$|\psi_0|^2$への一致、ヒストグラムから復元した浸透速度を確認します。
