添付は「クリフォード代数」シリーズの番外編（番号付き本編から独立した記事）で、幾何代数の挟み込みが原点を固定するという制約を、次元の追加によって乗り越える射影幾何代数 (PGA) と共形幾何代数 (CGA) を概説するものです。二重四元数の記事で示した$C\ell^+_{3,0,1}(\mathbb R)$との同型を受け、その全体像を与える位置づけです。読者は鏡映・回転子による挟み込みと、クリフォード代数の符号数を既知とします。以下の観点でレビューしてください。

- 数式・数学的主張の正しさ。特に次の導出を検算してください。
    - 平行な2平面の合成 $M = rq = 1 + \delta\,n e_0$ と、並進量が $2\delta\,n$ になること。平面 $n\cdot x + d = 0$ が原点から $-d$ の位置にあるという向きの取り方と、数値例（$x_3=1$ と $x_3=3$ の2平面で $P(2,3,5) \mapsto P(2,3,9)$）の整合。
    - 点の3ベクトル表現 $P(x) = e_{123} - x_1 e_{023} + x_2 e_{013} - x_3 e_{012}$ の各項の符号（3枚の平面の積を実際に展開して確認）。
    - CGAのヌル基底 $n_o, n_\infty$ の平方と内積、$P(x)\cdot P(y) = -\frac12|x-y|^2$、$S^2 = r^2$、$\pi^2 = 1$。
    - 並進子 $T_t = \exp(-\frac12 t\,n_\infty)$ が $P(x) \mapsto P(x+t)$ を与えること、拡大子 $D_\lambda = \exp(\frac\lambda2 n_o \wedge n_\infty)$ が $e^\lambda$ 倍になること（係数 $\frac12$ と符号）。
    - 単位球 $S_0 = n_o - \frac12 n_\infty$ による反転で $x \mapsto x/|x|^2$ となること。
    - 「$e_1,e_2,e_3,n_\infty$ が生成する部分代数が $C\ell_{3,0,1}(\mathbb R)$ と同型」という主張。$C\ell_{4,1}(\mathbb R)$ の中でこの4元が生成する部分代数が本当に16次元になるかを確認してください。
- 説明の分かりやすさ、論理の飛躍の有無。特に、PGAの平面 $p = ae_1+be_2+ce_3+de_0$（$n\cdot x + d = 0$）とCGAの平面 $\pi = n + d\,n_\infty$（原点から距離 $d$）で $d$ の符号規約が逆になっており、末尾で $p = n - d\,e_0$ と対応させています。この食い違いが読者に伝わる書き方になっているか。
- 用語・記法の一貫性。参照記事との照合を含めて確認してください。
    - **並進と無限遠の軸の関係**。本記事は「並進とは軸が無限遠に去った回転である」という見方を二重四元数の記事の後方参照として書いていますが、参照記事の側は改稿により、純並進は「回転角 $0$ のねじ運動」で軸の位置が定まらないことと、「軸を無限遠へ遠ざける純回転の極限」とを別の見方として区別しています。PGAでは平行2平面の交わりが無限遠直線になるため無限遠の軸に意味がありますが、本記事の書き方が参照記事の区別と食い違っていないか、引用の仕方が適切かを見てください。
    - 挟み込みの書き方。本記事の $X \mapsto pXp$、$X \mapsto M X \widetilde M$ が、回転の記事の挟み込み（$vxv^{-1}$ 型、符号の扱い、角度が倍になる規約）および二重四元数の記事の $\sigma(1+\varepsilon x)\overline{\sigma^*}$ と整合するか。
    - $\widetilde{\phantom M}$ を「反転」と呼んでいますが、CGA節の「球面反転」と同じ語になっています。参照記事での呼称に合わせるべきか、別語にすべきか。
    - クリフォード代数の記法。符号数 $(p,q,r)$ の三つ組と $C\ell_{4,1}(\mathbb R)$（$r$ を省略）の混在、偶部分代数 $C\ell^+$、擬スカラー、グレードの呼称（1ベクトル・2ベクトル・3ベクトル）が、二重四元数の記事の記法と一致しているか。
    - モーター（motor）と回転子（rotor）。rotor の訳語は「回転子」で統一する方針です。カタカナの「モーター」がこの方針の中で浮いていないか。
- 日本語表現の自然さ。あわせて次のプロジェクト方針に反する箇所を指摘してください。
    - `——`（em dash）を使わない。箇条書きの見出しと説明の区切りは全角コロン「：」。
    - 「正体」「種明かし」のような砕けた比喩を避ける。
- `&&&` ブロックの type の使い分けが内容に合っているか。単なる `&&&rem` に丸めず、`&&&def`・`&&&thm`・`&&&fml`・`&&&ex`・`&&&prf` を使い分ける方針です。証明を付けずに `&&&thm` としている箇所（交わる2平面の合成、PGAはCGAの部分代数）が適切か。

指摘事項を箇条書きで挙げてください。問題がなければその旨を書いてください。
