# 検討メモ：$C\ell_{2,0}(\mathbb R)$上の幾何微積分と複素解析

クリフォード代数の記事に追加しうる話題として、**代数の生成元で組んだ1階の微分演算子から複素解析を導く**道筋を整理した検討メモです。**記事化するかどうか自体が未確定です。**

[PLAN.md](../PLAN.md)の「幾何微積分と複素解析」に対応しますが、そこで挙げていたコーシーの積分定理・留数は**保留**とし、範囲を絞り込んだ状態を記録します。

## 確定した範囲

- **記号は$D$を使う**。$\nabla$は3次元のベクトル解析に固有の記号であり、次数付き構造を持つ本メモの文脈には合わない。$D$なら微分（derivative）とディラック（Dirac）を兼ねられる
- **2次元に特化する**。$C\ell_{2,0}(\mathbb R)$に限定し、一般次元のクリフォード解析には立ち入らない
- **到達点は「複素解析の別の見方」の導入に留める**。正則関数が何であるかを別の角度から述べるところまでで、複素解析の定理を証明し直すことは目指さない
- **有向積分は保留**。積分定理を扱うにはグリーンの定理から説明する必要があり、導入コストが範囲に見合わない。したがってコーシーの積分定理・積分公式・留数はすべて範囲外

この線引きにより、本メモの内容は**微分だけで完結**します。積分が要らないため、対象は代数の計算と偏微分に限られます。

数式は`sympy`で検証済みです（[check/memo-geometric-calculus.py](check/memo-geometric-calculus.py)）。

# ディラック作用素

$C\ell_{2,0}(\mathbb R)$の生成元を$e_1,e_2$（$e_1^2=e_2^2=1$、$e_1e_2=-e_2e_1$）とし、擬スカラーを$I=e_1e_2$と書きます。$I^2=-1$です。

&&&def ディラック作用素
$$
D = e_1\partial_x + e_2\partial_y
$$
&&&

生成元を係数として偏微分を束ねただけのものですが、これが果たす役割はクリフォード関係式から決まります。

&&&fml ラプラシアンの平方根
$$
D^2 = \partial_x^2 + \partial_y^2 = \Delta
$$
&&&

$e_i^2=1$から2乗の項が、$e_1e_2=-e_2e_1$から交差項の相殺が出ます。[`lie/`の検討メモ](../lie/MEMO.md)で述べた$D^2=\Delta$の、最小の実例にあたります。

&&&rem 符号数の選択
$e_i^2=-1$すなわち$C\ell_{0,2}(\mathbb R)\cong\mathbb H$を取ると$D^2=-\Delta$になります。ラプラシアンをそのまま得るには$C\ell_{2,0}(\mathbb R)\cong M_2(\mathbb R)$の側を選ぶ必要があります。四元数は平面の回転を表すには使えても、平面の微積分の舞台にはならないという違いです。
&&&

# モノジェニック関数とコーシー＝リーマンの方程式

$C\ell_{2,0}(\mathbb R)$の偶部分代数は$\{1,I\}$が張る2次元で、$I^2=-1$より$\mathbb C$と同型です。そこで値を偶部分に取る関数$F=u+Iv$を考えます。

$e_1I=e_2$、$e_2I=-e_1$を使うと

$$
DF = e_1(u_x - v_y) + e_2(u_y + v_x)
$$

となり、$DF=0$は次と同値です。

&&&fml モノジェニック性
$$
DF=0 \iff u_x = v_y,\quad u_y = -v_x
$$
&&&

右辺はコーシー＝リーマンの方程式そのものです。$DF=0$を満たす関数を**モノジェニック**と呼びます。正則性が、代数の生成元で組んだ1階の演算子の核として現れます。

## $e_1$を掛けると微分演算子になる

$e_1$は可逆（$e_1^2=1$）なので、上の同値は次の形に整理できます。

&&&fml ヴィルティンガー微分との対応
$$
e_1DF = (\partial_x + I\partial_y)F = 2\bar\partial F
$$
&&&

座標の側も同様で、ベクトル$\boldsymbol x = xe_1+ye_2$に$e_1$を左から掛けると

$$
e_1\boldsymbol x = x + Iy = z
$$

と、偶部分代数の元すなわち複素数になります。**ベクトルから$e_1$を剥がすと複素数になる**という対応で、複素平面がベクトル空間そのものではなく偶部分代数の側にあることが見えます。

# 次数による分岐

$D$は奇（次数を1つ上げ下げする）演算子なので、偶部分に作用させると値は奇部分に落ちます。奇部分の元は$G=e_1H$（$H$は偶）と書けるので、こちらでも同じ計算ができます。

$$
D(e_1H) = (\partial_x - I\partial_y)H = 2\partial H
$$

すなわち$DG=0$は$H$が**反正則**であることと同値です。偶の側と奇の側で、条件が共役の関係で入れ替わります。

&&&rem 分岐の理由
$e_1I e_1^{-1} = -I$、つまり$e_1$を掛ける操作は虚数単位の符号を反転させます。**複素共役は$e_1$による鏡映**であり（[鏡映：ベクトルから八元数まで](../vec-oct/01-reflection.md)）、正則と反正則の区別は代数の側では次数の区別に対応します。複素解析では$z$と$\bar z$の非対称性として現れるものが、ここでは$\mathbb Z_2$次数付き構造として現れます。
&&&

同じ理由で、左から作用させる$DF=0$と右から作用させる$FD=0$も別の条件になります。偶の$F$に対し$FD=0$は$u_x=-v_y,\ u_y=v_x$、すなわち反正則性です。左モノジェニックと右モノジェニックの区別は、積の非可換性が複素解析には見えない形で持っている情報です。

# 微分だけで言える帰結

積分定理を使わずに言えることを整理します。

- **成分は調和関数**。$D^2=\Delta$より、$DF=0$なら$\Delta F=0$で、各成分が調和になります。正則関数の実部・虚部が調和であるという事実が、平方根を取る前の演算子から直ちに出ます
- **コーシー核はベクトルの逆元**。$\boldsymbol x^2=|\boldsymbol x|^2$なので$\boldsymbol x^{-1}=\boldsymbol x/|\boldsymbol x|^2$であり、これは原点を除いて左右ともにモノジェニックです。$e_1\boldsymbol x^{-1}=1/\bar z$で、$1/z$という形式的な記号ではなく**ベクトルの逆元そのもの**が対応します。積分定理を保留する以上「核」とは呼べませんが、モノジェニックな具体例としては提示できます
- **発散と回転の統一**。値をベクトルに取る$F$に対し$DF = D\cdot F + D\wedge F$で、スカラー部が発散、2ベクトル部が回転です。モノジェニックとは両方が同時に消えることであり、ベクトル解析で別々に導入される2つの演算子が幾何積の分解に過ぎないことが見えます

# なぜ値が2成分になるのか

$\Delta$の平方根を取ろうとすると、値をスカラーに取ることができません。$D$は$e_1,e_2$を掛ける先を要求するため、関数は代数に値を取る必要があります。$C\ell_{2,0}(\mathbb R)\cong M_2(\mathbb R)$の最小左イデアルが2次元であることが、この要求の正体です。

複素関数が実部と虚部の2成分を持つことは、通常は複素数の定義から来る約束事として扱われます。本メモの見方では、**ラプラシアンの平方根が値を2成分に強制する**という形で説明が付きます。[`lie/`の検討メモ](../lie/MEMO.md)の「スピノルはベクトルの平方根」と同じ事実の、平面における最も単純な現れ方です。

# 保留した話題

いずれも本メモの範囲外とし、扱いません。

- **有向積分と幾何微積分の基本定理**。$\oint_{\partial M} d\boldsymbol S\,F = \int_M |dX|\,DF$の形でストークスの定理を統一するもの。$d\boldsymbol S$を多重ベクトル値の測度として扱う準備が要り、さらにグリーンの定理から説明する必要があるため、導入コストが範囲に見合わない
- **コーシーの積分定理・積分公式・留数定理**。上記の基本定理に依存するため、まとめて保留
- **一般次元のクリフォード解析**。留数の$2\pi$が$S^{n-1}$の面積に置き換わること、複素解析の定理が2次元固有ではないことなどは、積分を扱わない限り主張できない
- **多価性と対数**。単連結性の議論が要るため範囲外

# 検討事項

- **単発記事として成立するか**。積分定理を保留した結果、内容は「正則性の言い換え」と「調和性」「発散と回転の統一」に絞られる。到達点が明確でないまま道具立てだけを述べる記事にならないか、という点が最大の争点。**記事化の可否はここで決まる。**
- **到達点の候補**。「なぜ値が2成分になるのか」に答える構成が、現時点で最も記事らしい形だと考えている。複素数の定義を前提とせずに$\mathbb C$が出てくる筋道になり、[PLAN.md](../PLAN.md)の狙い（幾何代数ベースでの再構築）とも合う
- **前提知識の水準**。複素解析を知っている読者に別の見方を示すのか、知らない読者に複素数の出所を示すのかで、書き方が大きく変わる。前者なら短く書けるが読者が限られ、後者なら`qua/`側の記事との重複が生じる
- **保留の解除条件**。有向積分を持ち込むなら、グリーンの定理の説明を含めて独立した記事1本分になる。分けて書くか、この話題ごと当面書かないかの判断は、上の争点が決まってからでよい
- **配置**。書く場合は`clif/`の番号なし単発記事（[射影幾何代数と共形幾何代数](pga-cga.md)と同じ枠）とする。ただし主題が解析寄りであるため、`misc/`に置く選択肢もある
