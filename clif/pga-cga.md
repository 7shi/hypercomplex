二重四元数と剛体変換の記事では、二重数係数の四元数が退化クリフォード代数の偶部分代数$C\ell^+_{3,0,1}(\mathbb R)$と同型であることを示し、これが射影幾何代数 (PGA) や共形幾何代数 (CGA) への入り口になると述べました。[[7shi-dualq]] 本記事では、その2つの枠組みがどのような代数で、何を表せるようになるのかを概説します。

いずれも「幾何代数の挟み込みは原点を固定してしまう」という制約を、次元を追加することで乗り越える枠組みです。追加する次元の計量の選び方によってPGAとCGAに分かれ、扱える変換の範囲と計算の重さが変わります。全体像の提示を目的とし、個々の演算の詳細には深入りしません。番号付きの本編からは独立した記事です。

# 原点を固定するという制約

幾何代数では、鏡映も回転も$x \mapsto \pm vxv^{-1}$という挟み込みで表されました。[[7shi-mir]][[7shi-vrot]] この形の写像は$x$について線形なので、$x=0$は必ず$0$に移ります。すなわち**原点を通らない鏡映（平面）や、並進は表せません**。回転群$\mathrm{SO}(3)$は扱えても、剛体変換群$\mathrm{SE}(3)$には手が届かない、というのが素朴な幾何代数の限界です。

この壁は幾何代数に固有のものではなく、線形代数一般の事情です。標準的な対処法は次元を1つ増やすことで、3次元の点$(x,y,z)$を4次元の$(x,y,z,1)$と表せば、並進を含むアフィン変換が$4\times4$行列の線形写像として書けます。同次座標の考え方です。[[7shi-homog]]

幾何代数で同じことをする場合、増やした次元の**計量**をどう選ぶかという自由度が生じます。ここが分岐点です。

&&&rem 2つの選択肢
- 平方が$0$になる生成元を1つ加える（退化計量）と、$C\ell_{3,0,1}(\mathbb R)$を舞台とする**射影幾何代数 (PGA)** が得られ、剛体変換$\mathrm{SE}(3)$がちょうど収まります。
- 平方が$+1$と$-1$の生成元を1つずつ加える（ローレンツ計量）と、$C\ell_{4,1}(\mathbb R)$を舞台とする**共形幾何代数 (CGA)** が得られ、剛体変換に加えて拡大・反転を含む共形変換まで扱えます。
&&&

以下、3次元空間$\mathbb R^3$の直交基底を$e_1,e_2,e_3$（$e_a^2=+1$）とし、点$x=(x_1,x_2,x_3)$をベクトル$x = x_1e_1+x_2e_2+x_3e_3$と同一視します。

# 射影幾何代数 (PGA)

## 退化した生成元

&&&def $C\ell_{3,0,1}(\mathbb R)$
$e_1,e_2,e_3$（$e_a^2=+1$）に、これらと反交換する生成元$e_0$を加え、

$$
e_0^2 = 0
$$

とします。符号数$(p,q,r)=(3,0,1)$は平方が$+1,-1,0$となる生成元の個数で、$r=1$が退化部分です。生成される代数は$2^4=16$次元です。
&&&

$e_0$は二重数の$\varepsilon$と同じ$\varepsilon^2=0$という性質を持ちますが、$\varepsilon$が他のすべてと可換だったのに対し、$e_0$は生成元として他と**反交換**する点が異なります。

## 平面を1ベクトルとする

PGAの特徴は、1ベクトルが点ではなく**平面**を表すことです。

&&&def 平面の埋め込み
平面$a x_1 + b x_2 + c x_3 + d = 0$に、1ベクトル

$$
p = a e_1 + b e_2 + c e_3 + d e_0
$$

を対応させます。$e_0^2=0$より

$$
p^2 = a^2+b^2+c^2
$$

となり、法線$(a,b,c)$が単位ベクトルなら$p^2=1$です。以下、平面はこの意味で正規化されているものとします。
&&&

&&&rem なぜ平面が1ベクトルなのか
幾何代数において1ベクトル$v$の役割は、$v$に直交する超平面での鏡映の生成元でした。[[7shi-mir]] 剛体変換をすべて鏡映の合成で組み立てたいなら、生成元が担うべき対象は「原点を通る超平面」ではなく「任意の位置にある平面」です。1ベクトルに平面を割り当てるのは、この要請に素直に従った結果です。$d$の項が平面を原点から引き離す役割を持ち、そのための座標が$e_0$です。
&&&

点は3ベクトルとして、3枚の平面の交わりから得られます。

&&&ex 点の表現
点$x=(x_1,x_2,x_3)$を通り各座標軸に垂直な3枚の平面$e_1 - x_1 e_0$、$e_2 - x_2 e_0$、$e_3 - x_3 e_0$の積を取ると

$$
P(x) = e_{123} - x_1\, e_{023} + x_2\, e_{013} - x_3\, e_{012}
$$

となります（$e_{abc} := e_ae_be_c$と略記）。原点は$P(0)=e_{123}$です。$e_{123}$の係数が同次座標の第4成分にあたり、係数全体を定数倍しても同じ点を表します。
&&&

&&&rem グレードと幾何的対象
| グレード | 次元 | 表す対象 |
|:--:|:--:|:--|
| 0（スカラー） | 1 | ― |
| 1（1ベクトル） | 4 | 平面（$e_0$のみ：無限遠平面） |
| 2（2ベクトル） | 6 | 直線（$e_0$を含む：無限遠直線） |
| 3（3ベクトル） | 4 | 点（$e_{123}$の係数が$0$：無限遠点＝方向） |
| 4（擬スカラー） | 1 | ― |

$e_0$を因子に持つ要素は無限遠にある対象を表します。「平行な2平面は無限遠直線で交わる」といった射影幾何の言い回しが、そのまま代数の等式として成り立ちます。
&&&

## 鏡映から並進へ

正規化された平面$p$による鏡映は、対象のグレードによらず挟み込みで書けます。

&&&fml 平面による鏡映
$$
X \mapsto p X p
$$

（PGAの要素は同次座標なので、全体の符号は無視できます。）
&&&

2枚の平面で続けて鏡映すると、その合成$M = rq$による挟み込み$X \mapsto M X \widetilde M$（$\widetilde{\phantom M}$は反転）が得られます。ここからが本題で、2平面の位置関係によって回転と並進が振り分けられます。

&&&thm 平行な2平面の合成は並進
単位法線$n$を共有する2枚の平面$q = n + d_1 e_0$、$r = n + d_2 e_0$に対して、$\delta := d_1 - d_2$とおくと

$$
M = rq = 1 + \delta\, n e_0
$$

であり、これは$2\delta\, n$方向への並進を与えます。2ベクトル$ne_0$は$(ne_0)^2 = -n^2 e_0^2 = 0$と冪零です。
&&&

&&&prf
$e_0$が$n$と反交換すること（$e_0 n = -n e_0$）と$e_0^2=0$から

$$
rq = (n + d_2 e_0)(n + d_1 e_0) = n^2 + d_1 n e_0 + d_2 e_0 n = 1 + (d_1 - d_2) n e_0
$$

となります。2枚の平面は$n$方向に測って原点から$-d_1, -d_2$の位置にあるので、間隔は$|\delta|$です。平行な2枚の鏡で反射すると間隔の2倍だけ平行移動するという初等的な事実が、$2\delta\,n$という並進として現れます。
&&&

&&&ex 平面$x_3=1$と$x_3=3$
$q = e_3 - e_0$、$r = e_3 - 3e_0$とすると$\delta = -1-(-3) = 2$で、$M = rq = 1 - 2e_0e_3$です。点$P(2,3,5)$を挟み込むと$P(2,3,9)$が得られ、間隔$2$の2倍だけ$x_3$方向に動きます。
&&&

&&&thm 交わる2平面の合成は回転
原点を通る2枚の平面が角$\theta$で交わるとき、合成$M = rq$は交線を軸とする角$2\theta$の回転を与えます。例えば$q = e_1$、$r = \cos\theta\, e_1 + \sin\theta\, e_2$のとき

$$
M = rq = \cos\theta - \sin\theta\, e_1e_2
$$

となり、これは$e_1e_2$（$x_3$軸）を軸とする角$2\theta$の回転子です。
&&&

回転子が「2枚の鏡映の合成」であったことは既に見た通りですが[[7shi-vrot]]、PGAではそれと同じ操作が、平面の平行・非平行という条件だけで回転と並進に分かれます。並進とは「軸が無限遠に去った回転」であるというねじ運動の見方が、代数の側から自然に再現されます。[[7shi-dualq]]

## モーターと二重四元数

偶数個の平面の積として得られる要素を**モーター** (motor, motion + rotor) と呼びます。これは偶部分代数$C\ell^+_{3,0,1}(\mathbb R)$の元で、スカラー$1$、6個の2ベクトル、擬スカラー$e_{0123}$が張る8次元です。

&&&rem 二重四元数との対応
この8次元の偶部分代数が二重四元数$\mathbb H \otimes \mathbb D$と同型であることは、二重四元数の記事で確認しました。[[7shi-dualq]] 二重四元数による剛体変換$\sigma = (1 + \frac\varepsilon2 t) r$は、PGAのモーターを偶部分だけ切り出して見たものです。逆に言えば、PGAは二重四元数に「平面・直線・点そのもの」という奇グレードの住人を補って16次元に広げた枠組みだと言えます。$\mathrm{SE}(3)$の次元$6$が2ベクトルの個数$\binom42=6$と一致し、モーターがねじ運動$\exp$として書けることも、二重四元数の側で見た通りです。
&&&

## 退化の代償

退化計量には代償もあります。擬スカラー$e_{0123}$は$e_0$を含むため平方が$0$で、可逆ではありません。したがって非退化な幾何代数のように「擬スカラーを掛ける」ことで双対（結び・交わりの交換）を定義できず、係数の並べ替えとして双対写像を別途用意する必要があります。また、$e_0$方向の計量が潰れているため、内積から距離が直接読める場面が限られます。次に見るCGAは、この点を非退化な計量によって補う枠組みです。

# 共形幾何代数 (CGA)

## ヌル基底

CGAでは次元を2つ増やし、符号を1つずつ振り分けます。

&&&def $C\ell_{4,1}(\mathbb R)$とヌル基底
$e_1,e_2,e_3$に、$e_+^2 = +1$、$e_-^2 = -1$となる生成元を加えた$2^5 = 32$次元の代数を考えます。ここで

$$
n_o := \frac{e_- - e_+}2, \quad n_\infty := e_- + e_+
$$

とおくと

$$
n_o^2 = n_\infty^2 = 0, \quad n_o \cdot n_\infty = -1
$$

が成り立ちます。$n_o$は原点、$n_\infty$は無限遠点を表します。
&&&

平方が$0$のベクトルを**ヌルベクトル**と呼びます。PGAでは退化計量によって冪零な方向を用意しましたが、CGAでは非退化なローレンツ計量の中に生じるヌル方向がその役目を担います。計量そのものは非退化なので、擬スカラーは可逆で双対も普通に定義できます。

## 点はヌルベクトルに乗る

&&&def 点の埋め込み
$x \in \mathbb R^3$に対して

$$
P(x) := n_o + x + \frac12 |x|^2 n_\infty
$$

と定めます。$P(x)^2 = 0$であり、点は5次元空間のヌル錐（平方が$0$のベクトル全体）の上に乗ります。$x=0$では$P(0) = n_o$です。
&&&

この埋め込みの効用は、内積が距離を与えることです。

&&&fml 内積と距離
$$
P(x) \cdot P(y) = -\frac12 |x-y|^2
$$
&&&

&&&prf
$n_o \cdot n_\infty = -1$、$n_o^2 = n_\infty^2 = 0$、および$x,y$が$n_o,n_\infty$と直交することから

$$
P(x)\cdot P(y) = \underbrace{x\cdot y}_{\text{3次元部分}} + \left(-\frac12|y|^2\right) + \left(-\frac12|x|^2\right) = -\frac12|x-y|^2
$$

となります。$n_o$と$\frac12|y|^2 n_\infty$の対、$\frac12|x|^2n_\infty$と$n_o$の対がそれぞれ$-\frac12|y|^2, -\frac12|x|^2$を出します。
&&&

点が「$P^2=0$」、2点の一致が「$P\cdot Q = 0$」という代数的な条件で書け、距離が内積として読めます。PGAが苦手とした計量的な情報が、ここでは代数に組み込まれています。

## 球も平面も1ベクトル

&&&def 球と平面
中心$c$、半径$r$の球、および単位法線$n$で原点から距離$d$の平面を

$$
S := P(c) - \frac12 r^2 n_\infty, \qquad
\pi := n + d\, n_\infty
$$

と定めます。どちらも1ベクトルで、$S^2 = r^2$、$\pi^2 = 1$です。点$P$がこれらの上にあることは

$$
P \cdot S = 0, \qquad P \cdot \pi = 0
$$

と表されます。
&&&

&&&rem 平面は半径無限大の球
$S$の定義で中心を$n$方向へ遠ざけながら半径を大きくすると、極限として$\pi$が得られます。CGAでは平面は球の特別な場合であり、両者を区別せず同じ1ベクトルとして扱えます。この「球と平面の同列化」が、次に見る反転の自由な取り扱いを支えます。
&&&

## 鏡映は反転を含む

1ベクトルによる挟み込みは、ここでも鏡映です。ただし1ベクトルが球にもなり得るため、鏡映の意味が広がります。

&&&fml 球による鏡映＝反転
$$
X \mapsto S X S
$$

は球$S$に関する反転（球面反転）を与えます。
&&&

&&&ex 単位球による反転
原点中心の単位球$S_0 = n_o - \frac12 n_\infty$で点$P(x)$を挟むと、$x/|x|^2$を表す点が得られます（同次座標なので全体の定数倍は無視します）。例えば$x = (1,2,-1)$（$|x|^2=6$）は$\frac16(1,2,-1)$に移ります。
&&&

平面による鏡映が通常の鏡映であることも同じ式から従い、平面と球を混ぜて合成すれば、剛体変換・拡大・反転がすべて同じ挟み込みの言葉で扱えます。

## 並進と拡大

&&&fml 並進子と拡大子
$$
T_t = \exp\left(-\frac12 t\, n_\infty\right) = 1 - \frac12 t\, n_\infty, \qquad
D_\lambda = \exp\left(\frac\lambda2 n_o \wedge n_\infty\right)
$$

は、それぞれ$t$だけの並進と、原点中心の$e^\lambda$倍の拡大を与えます（$X \mapsto V X \widetilde V$）。$t \cdot n_\infty = 0$と$n_\infty^2=0$から$(t\,n_\infty)^2 = 0$となるため、$T_t$の指数関数は2項で厳密に閉じます。
&&&

&&&ex 並進の確認
$T_t P(x) \widetilde{T_t} = P(x+t)$が成り立ちます。回転子と同じ形の挟み込みで、点が素直に平行移動します。
&&&

$C\ell_{4,1}(\mathbb R)$の2ベクトルは$\binom52 = 10$次元で、これは3次元共形変換群の次元（回転3＋並進3＋拡大1＋特殊共形変換3）と一致します。挟み込みで実現できる変換の全体は、ちょうど共形群$\mathrm O(4,1)$にあたります。

&&&rem 角度を保つ変換
共形変換とは角度を保つ変換のことです。距離までは保たないため剛体変換より広く、拡大や反転を含みます。リウヴィルの定理により、3次元以上の共形変換は「剛体変換・拡大・反転の合成」に限られます。CGAはその全体をちょうど覆う枠組みです。
&&&

# 2つの枠組みの比較

| | PGA | CGA |
|:--|:--|:--|
| 代数（3次元用） | $C\ell_{3,0,1}(\mathbb R)$（16次元） | $C\ell_{4,1}(\mathbb R)$（32次元） |
| 追加する生成元 | $e_0$（$e_0^2=0$） | $e_+, e_-$（ヌル基底$n_o, n_\infty$） |
| 1ベクトル | 平面 | 球・平面 |
| 点 | 3ベクトル | 1ベクトル（ヌル） |
| 扱える変換 | 剛体変換$\mathrm{SE}(3)$ | 共形変換（剛体変換＋拡大＋反転） |
| 2ベクトルの次元 | 6（$=\dim\mathrm{SE}(3)$） | 10（$=\dim\mathrm O(4,1)$） |
| 偶部分代数 | 8次元＝二重四元数 | 16次元 |
| 計量 | 退化（擬スカラーが非可逆） | 非退化 |
| 距離 | 直接は読めない | 内積$P\cdot Q = -\frac12|x-y|^2$ |

剛体変換だけを扱いたい用途（姿勢制御・ロボティクス・コンピューターグラフィックス）ではPGAが軽く、円や球の交わり、距離を含む構成を扱いたい用途ではCGAが強い、という住み分けになります。

# 冪零な方向が並進を生む

3つの枠組みに共通する仕掛けを取り出しておきます。

&&&fml 並進の共通構造
- 二重四元数：$\varepsilon^2 = 0$、並進は$1 + \frac\varepsilon2 t$。[[7shi-dualq]]
- PGA：$(ne_0)^2 = 0$、並進は$1 + \delta\, n e_0$。
- CGA：$(t\,n_\infty)^2 = 0$、並進は$1 - \frac12 t\, n_\infty$。

いずれも平方が$0$になる2ベクトル$B$を指数の肩に乗せたもので、$\exp(B) = 1 + B$と1次で厳密に閉じます。
&&&

回転が$B^2 = -1$の2ベクトルによる$\exp$（三角関数）で表されたのに対し、並進は$B^2 = 0$の2ベクトルによる$\exp$（1次で停止）で表されます。二重四元数の記事で見た擬スカラーの三分法（$\omega^2 = -1, +1, 0$）と同じ構図が、変換の側でも繰り返されています。

さらに、PGAはCGAの中に含まれています。

&&&thm PGAはCGAの部分代数
$n_\infty$は$e_1,e_2,e_3$と反交換し$n_\infty^2 = 0$を満たすので、$e_1,e_2,e_3,n_\infty$が生成する部分代数は$C\ell_{3,0,1}(\mathbb R)$と同型です（$e_0 \leftrightarrow n_\infty$）。
&&&

CGAの平面$\pi = n + d\,n_\infty$とPGAの平面$p = n - d\,e_0$が対応することからも見て取れるように、CGAで無限遠点$n_\infty$を固定する変換に制限したものがPGA、すなわち剛体変換です。無限遠点を動かす自由を認めると拡大と反転が加わり、共形変換に広がります。

# まとめ

- 幾何代数の挟み込みは線形写像なので原点を固定します。並進を含めるには次元を追加する必要があり、追加する次元の計量の選び方でPGAとCGAに分かれます。
- PGAは$C\ell_{3,0,1}(\mathbb R)$を舞台とし、1ベクトルが平面、2ベクトルが直線、3ベクトルが点を表します。2枚の平面による鏡映の合成が、交わる場合は回転、平行な場合は並進を与え、剛体変換$\mathrm{SE}(3)$が鏡映の合成としてすべて得られます。
- PGAの偶部分代数は8次元で、二重四元数と同型です。二重四元数はPGAの偶部分を取り出したものにあたります。
- CGAは$C\ell_{4,1}(\mathbb R)$を舞台とし、点をヌルベクトル$P(x) = n_o + x + \frac12|x|^2 n_\infty$として埋め込みます。内積が距離$P\cdot Q = -\frac12|x-y|^2$を与え、1ベクトルは球と平面を表します。球による鏡映が反転となり、剛体変換・拡大・反転を含む共形変換全体が挟み込みで扱えます。
- 並進はいずれの枠組みでも「平方が$0$の2ベクトルの指数関数」として現れ、$\exp(B) = 1 + B$と1次で閉じます。$n_\infty$を固定する部分としてPGAがCGAに含まれます。
