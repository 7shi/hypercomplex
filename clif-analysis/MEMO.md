# 検討メモ：クリフォード解析シリーズ

ディラック作用素を軸に、複素解析から四元数解析・クリフォード解析へ進むシリーズ`clif-analysis`の検討メモです。公開向けの構想は[README.md](README.md)にまとめ、本メモには判断の経緯と未解決の争点を残します。

[PLAN.md](../PLAN.md)の「幾何微積分と複素解析」に対応します。当初は`clif/`に置く単発記事として検討していましたが、単発では有向積分の導入コストが範囲に見合わず、コーシーの積分定理・留数をすべて保留せざるを得ませんでした。その結果、内容が「正則性の言い換え」に留まって到達点が立たないことが最大の争点になっていました。シリーズ化によってこの争点は解消されます。導入コストを複数の記事に分散できるため、**保留していた積分定理はすべて範囲内に戻します**。

数式は`sympy`で検証済みです（[check/memo-geometric-calculus.py](check/memo-geometric-calculus.py)）。ただし検証が及ぶのは第1回の内容までで、第4回以降は執筆時に別途検証が要ります。

## 確定した範囲

- **記号は$D$を使う**。$\nabla$は3次元のベクトル解析に固有の記号であり、次数付き構造を持つ本シリーズの文脈には合わない。$D$なら微分（derivative）とディラック（Dirac）を兼ねられる
- **選別の基準は「高次元に持ち上がるか」**。複素解析編は教科書の再構成ではなく、四元数解析・クリフォード解析への準備として必要な部分に限る。この基準により、テイラー展開・等角写像・リーマン面などは最初から範囲外と言い切れる
- **前提知識は複素解析を仮定しない側に取る**。シリーズであれば紙幅が確保できるため、複素数の定義を前提とせずに$\mathbb C$が現れる筋道を書ける。[PLAN.md](../PLAN.md)の狙い（幾何代数ベースでの再構築）とも合う
- **八元数解析は扱わない**。非結合性のため、作用素の左右の作用が結合子で絡んで枠組みが立たない。触れるとしても注記に留める
- **曲がった空間上のディラック作用素は扱わない**。スピン構造・スピン接続は[PLAN.md](../PLAN.md)の「K理論と指数定理」に委ねる

| # | 内容 | 到達点 |

| 01 | $C\ell_{2,0}(\mathbb R)$のディラック作用素とモノジェニック関数 | ラプラシアンの平方根が値を2成分に強制する |
| 02 | 有向積分と幾何微積分の基本定理 | グリーン・ストークス・発散定理が1つの式の特別な場合 |
| 03 | コーシーの積分定理・積分公式・留数 | $1/z$がベクトルの逆元であり、$2\pi$が$S^1$の周長であること |
| 04 | 四元数解析（フューター正則関数） | 積・合成・冪が正則性を保たない |
| 05 | クリフォード解析（一般次元） | 留数の$2\pi$が$S^{n-1}$の面積に置き換わる |
| 06 | 総括 | 複素解析の何が可換性由来で、何が2次元固有だったのか |

四元数解析（04）を一般次元（05）より先に置きます。論理的にはフューター作用素は$C\ell_{0,3}(\mathbb R)$の理論の特別な場合ですが、読者にとって$\mathbb H$は既知の代数であり、そこで破綻に出会うことが一般論へ進む動機付けになります。$\mathbb H$単体では説明の付かない部分（左正則と右正則の分裂、なぜ$\mathbb H$値でよいのか）を残しておき、05で回収します。

04がシリーズの山場です。複素解析で自明に見えた性質が、**非可換性のせいで壊れるもの**と**次元のせいで壊れるもの**に分かれる、という切り分けが06の総括に直結し、シリーズ全体の主張になります。

# 01 ディラック作用素とモノジェニック関数

$C\ell_{2,0}(\mathbb R)$の生成元を$e_1,e_2$（$e_1^2=e_2^2=1$、$e_1e_2=-e_2e_1$）とし、擬スカラーを$I=e_1e_2$と書きます。$I^2=-1$です。

&&&def ディラック作用素
$$
D = e_1\partial_x + e_2\partial_y
$$
&&&

生成元を係数として偏微分を束ねただけのものですが、これが果たす役割はクリフォード関係式から決まります。

&&&fml ラプラシアンの平方根
$$
D^2 = \partial_x^2 + \partial_y^2 = \Delta
$$
&&&

$e_i^2=1$から2乗の項が、$e_1e_2=-e_2e_1$から交差項の相殺が出ます。[`lie/`の検討メモ](../lie/MEMO.md)で述べた$D^2=\Delta$の、最小の実例にあたります。

&&&rem 符号数の選択
$e_i^2=-1$すなわち$C\ell_{0,2}(\mathbb R)\cong\mathbb H$を取ると$D^2=-\Delta$になります。ラプラシアンをそのまま得るには$C\ell_{2,0}(\mathbb R)\cong M_2(\mathbb R)$の側を選ぶ必要があります。四元数は平面の回転を表すには使えても、平面の微積分の舞台にはならないという違いです。
&&&

## モノジェニック関数とコーシー＝リーマンの方程式

$C\ell_{2,0}(\mathbb R)$の偶部分代数は$\{1,I\}$が張る2次元で、$I^2=-1$より$\mathbb C$と同型です。そこで値を偶部分に取る関数$F=u+Iv$を考えます。

$e_1I=e_2$、$e_2I=-e_1$を使うと

$$
DF = e_1(u_x - v_y) + e_2(u_y + v_x)
$$

となり、$DF=0$は次と同値です。

&&&fml モノジェニック性
$$
DF=0 \iff u_x = v_y,\quad u_y = -v_x
$$
&&&

右辺はコーシー＝リーマンの方程式そのものです。$DF=0$を満たす関数を**モノジェニック**と呼びます。正則性が、代数の生成元で組んだ1階の演算子の核として現れます。

## $e_1$を掛けると微分演算子になる

$e_1$は可逆（$e_1^2=1$）なので、上の同値は次の形に整理できます。

&&&fml ヴィルティンガー微分との対応
$$
e_1DF = (\partial_x + I\partial_y)F = 2\bar\partial F
$$
&&&

座標の側も同様で、ベクトル$\boldsymbol x = xe_1+ye_2$に$e_1$を左から掛けると

$$
e_1\boldsymbol x = x + Iy = z
$$

と、偶部分代数の元すなわち複素数になります。**ベクトルから$e_1$を剥がすと複素数になる**という対応で、複素平面がベクトル空間そのものではなく偶部分代数の側にあることが見えます。

この$e_1$倍は、後述する2つの路線（ベクトル変数とパラベクトル変数）が2次元では一致することの現れでもあります。高次元ではこの操作に対応するものがないため、路線が分かれます。

## 次数による分岐

$D$は奇（次数を1つ上げ下げする）演算子なので、偶部分に作用させると値は奇部分に落ちます。奇部分の元は$G=e_1H$（$H$は偶）と書けるので、こちらでも同じ計算ができます。

$$
D(e_1H) = (\partial_x - I\partial_y)H = 2\partial H
$$

すなわち$DG=0$は$H$が**反正則**であることと同値です。偶の側と奇の側で、条件が共役の関係で入れ替わります。

&&&rem 分岐の理由
$e_1I e_1^{-1} = -I$、つまり$e_1$を掛ける操作は虚数単位の符号を反転させます。**複素共役は$e_1$による鏡映**であり（[鏡映：ベクトルから八元数まで](../vec-oct/01-reflection.md)）、正則と反正則の区別は代数の側では次数の区別に対応します。複素解析では$z$と$\bar z$の非対称性として現れるものが、ここでは$\mathbb Z_2$次数付き構造として現れます。
&&&

同じ理由で、左から作用させる$DF=0$と右から作用させる$FD=0$も別の条件になります。偶の$F$に対し$FD=0$は$u_x=-v_y,\ u_y=v_x$、すなわち反正則性です。左モノジェニックと右モノジェニックの区別は、積の非可換性が複素解析には見えない形で持っている情報です。2次元では共役を取るだけの違いですが、04でこの区別が本質的になります。

## 微分だけで言える帰結

- **成分は調和関数**。$D^2=\Delta$より、$DF=0$なら$\Delta F=0$で、各成分が調和になります。正則関数の実部・虚部が調和であるという事実が、平方根を取る前の演算子から直ちに出ます
- **コーシー核はベクトルの逆元**。$\boldsymbol x^2=|\boldsymbol x|^2$なので$\boldsymbol x^{-1}=\boldsymbol x/|\boldsymbol x|^2$であり、これは原点を除いて左右ともにモノジェニックです。$e_1\boldsymbol x^{-1}=1/\bar z$で、$1/z$という形式的な記号ではなく**ベクトルの逆元そのもの**が対応します。核と呼べる根拠は03で与えます
- **発散と回転の統一**。値をベクトルに取る$F$に対し$DF = D\cdot F + D\wedge F$で、スカラー部が発散、2ベクトル部が回転です。モノジェニックとは両方が同時に消えることであり、ベクトル解析で別々に導入される2つの演算子が幾何積の分解に過ぎないことが見えます

## なぜ値が2成分になるのか

$\Delta$の平方根を取ろうとすると、値をスカラーに取ることができません。$D$は$e_1,e_2$を掛ける先を要求するため、関数は代数に値を取る必要があります。$C\ell_{2,0}(\mathbb R)\cong M_2(\mathbb R)$の最小左イデアルが2次元であることが、この要求の出所です。

複素関数が実部と虚部の2成分を持つことは、通常は複素数の定義から来る約束事として扱われます。本シリーズの見方では、**ラプラシアンの平方根が値を2成分に強制する**という形で説明が付きます。[`lie/`の検討メモ](../lie/MEMO.md)の「スピノルはベクトルの平方根」と同じ事実の、平面における最も単純な現れ方です。

これを第1回の到達点とします。複素数の定義を前提とせずに$\mathbb C$が出てくる筋道であり、単発記事案の時点で唯一まとまった到達点候補だったものです。

# 02 有向積分と幾何微積分の基本定理

単発案で保留していた項目です。シリーズなら独立1本を立てられるため、範囲内に戻します。

- $d\boldsymbol S$を多重ベクトル値の測度として導入し、基本定理$\oint_{\partial M} d\boldsymbol S\,F = \int_M |dX|\,DF$を述べる
- グリーンの定理・ストークスの定理・発散定理が、次数と符号数の選び方だけが違う同じ式であることを見る。**これ自体が独立した到達点**であり、03への準備という位置づけに留まらない
- 非可換な場合に備えて、両側形式$\oint_{\partial M} G\,d\boldsymbol S\,F = \int_M |dX|\,(GDF)$（$G$は右から、$F$は左から作用）まで用意しておく。04・05で必要になる

$C\ell_{2,0}(\mathbb R)$に限定するか一般次元で述べるかは未決です。

# 03 コーシーの積分定理・積分公式・留数

02の基本定理に$DF=0$を代入すれば積分定理が出ます。核として$\boldsymbol x^{-1}$を使えば積分公式が、留数はその係数として読めます。

- $2\pi$が$S^1$の周長として現れることを明示しておく。05でこれが$S^{n-1}$の面積に置き換わるため、**ここで$2\pi$の出所を幾何的に押さえておくことが05の伏線になる**
- 多価性と対数は単連結性の議論が要るため、引き続き範囲外とする

# 04 四元数解析

シリーズの山場です。フューター（Fueter）の意味で正則な四元数値関数を扱います。

$q = x_0 + x_1i + x_2j + x_3k$に対し、作用素は次のものです。

$$
D = \partial_0 + i\partial_1 + j\partial_2 + k\partial_3,\qquad
\bar D = \partial_0 - i\partial_1 - j\partial_2 - k\partial_3
$$

$i,j,k$が対ごとに反交換して2乗が$-1$であることから$\bar DD = D\bar D = \Delta_4$が出ます。**01の$D^2=\Delta$とは形が違い、共役との積になる**点に注意が要ります。$Df=0$を満たす$f$を左正則、$fD=0$を満たすものを右正則と呼びます。

## 破綻の一覧

- **恒等写像が正則でない**。$Dq = 1 + i\cdot i + j\cdot j + k\cdot k = 1-3 = -2 \ne 0$。したがって$q^n$も一般に正則でない
- **積が正則にならない**。$f,g$が左正則でも$fg$は一般に左正則でない。非可換性のため、ライプニッツ則が$D$を$f$と$g$に分配する形にならない
- **合成が正則にならない**。したがって等角写像に相当するものがない
- **冪級数が使えない**。代わりにフューター多項式（$\zeta_l = x_l - x_0e_l$の対称化積）を基底に取る

一方で生き残るものもあります。成分の調和性（$\bar DD=\Delta_4$から直ちに出る）、コーシー＝フューターの積分公式（核は$\bar q/|q|^4 = q^{-1}/|q|^2$）、平均値の性質、最大値原理などです。

## フューターの定理

複素解析との橋として、フューターの定理を置く案があります。1変数の正則関数$f(z)=u+iv$から

$$
\tilde f(q) = u(x_0,|\boldsymbol q|) + \frac{\boldsymbol q}{|\boldsymbol q|}\,v(x_0,|\boldsymbol q|)
$$

を作ると$\Delta\tilde f$が左正則になる、というものです（$\boldsymbol q$は純虚部）。03からの接続として自然で、正則関数の在庫を確保する手段にもなります。ただしラプラシアンを1回かぶせるという操作の必然性の説明が難しく、入れるかどうかは未決です。

# 05 クリフォード解析

一般の$C\ell_{0,n}(\mathbb R)$でモノジェニック関数を扱い、04を特別な場合として回収します。

- **$\mathbb H$の位置づけ**。$\omega = e_1e_2e_3$は$C\ell_{0,3}(\mathbb R)$の中心元で$\omega^2=+1$を満たすため、$(1\pm\omega)/2$による直和分解$C\ell_{0,3}(\mathbb R)\cong\mathbb H\oplus\mathbb H$が成り立ちます。四元数解析は、$C\ell_{0,3}(\mathbb R)$のパラベクトル変数による理論を、$\omega=-1$すなわち$ijk=-1$の側の成分に落としたものにあたります。**04で「$\mathbb H$値でよい理由」を保留しておき、ここで答える**
- **コーシー核**。$\boldsymbol x^{-1}$の一般化$\bar{\boldsymbol x}/|\boldsymbol x|^n$と、正規化定数$\omega_{n-1} = 2\pi^{n/2}/\Gamma(n/2)$（$S^{n-1}$の面積）。03の$2\pi$が$n=2$の場合であることを確認する
- **左右の区別**。非可換性から左モノジェニックと右モノジェニックが分かれ、両側形式の基本定理（02）が必要になる
- **調和解析との接続**。$D$が$d+\delta$にあたること、球面調和関数の一般化としての球面モノジェニックス

# 06 総括

複素解析の性質を、壊れ方の原因で仕分けます。

| 由来 | 該当するもの |
|---|---|
| 非可換性で壊れる | 積・合成の閉包性、冪級数、等角写像 |
| 次元で変わる | 留数の孤立性、ローラン展開の形、$2\pi$の値 |
| 壊れない | 調和性、コーシーの積分公式、平均値の性質、最大値原理 |

等角写像については、リウヴィルの定理（3次元以上では等角写像はメビウス変換に限る）を挙げれば、複素解析の豊かさが2次元固有であることを一言で示せます。

01で見た$e_1$倍による「ベクトル変数と複素変数の同一視」が2次元固有の現象であり、高次元ではベクトル変数の理論（$C\ell_{0,n}(\mathbb R)$のディラック作用素）とパラベクトル変数の理論（04・05のコーシー＝リーマン型作用素）が別物として分かれる、という総括も置けます。

# 検討事項

- **ベクトル変数とパラベクトル変数の路線をどう繋ぐか**。**現時点で最大の争点。** 01は$C\ell_{2,0}(\mathbb R)$のベクトル変数$\boldsymbol x = xe_1+ye_2$とディラック作用素$D=e_1\partial_x+e_2\partial_y$を取りますが、04の四元数解析は変数にスカラー部を含むパラベクトル$q=x_0+x_1i+x_2j+x_3k$と$D=\partial_0+i\partial_1+\cdots$を取ります。2次元では$e_1$倍で両者が移り合うため差が見えませんが、高次元では別の理論です。次の3案がある
  - **(A) 全編パラベクトル**。01を$C\ell_{0,1}(\mathbb R)\cong\mathbb C$のパラベクトル$x_0+x_1e_1$から始める。統一は取れるが、01の主張（$D^2=\Delta$、値が2成分になること）が出ない
  - **(B) 01のみベクトル、04以降パラベクトル**。01の到達点は守れるが、路線の切り替えを説明する必要がある。切り替えの説明を06の総括に回せるなら、切り替えそのものが内容になる
  - **(C) 全編ベクトル**。四元数解析（フューター）が扱えなくなるため、シリーズの前提と矛盾する
  - 現時点では**(B)**を推す。01の「$e_1$を掛けると微分演算子になる」節が既に両路線の橋になっており、そこに一言添えるだけで伏線が張れる
- **02を一般次元で述べるか$C\ell_{2,0}(\mathbb R)$に限定するか**。一般で述べれば05が軽くなるが、01からの落差が大きい
- **04にフューターの定理を入れるか**。03からの橋としては自然だが、$\Delta$をかぶせる操作の必然性が説明しにくい
- **記事数**。6本は多い可能性がある。02と03、04と05をそれぞれ統合して4本にする案もあるが、02は単体で到達点（ストークスの統一）を持つため分けたい
- **`lebesgue/`との棲み分け**。どちらも解析系だが、測度論と有向積分で対象が異なるため衝突しない。ただし本の構成段階では解析系として隣接することになる
- **検証コード**。現在あるのは01の分のみ。04（フューター作用素、$\bar DD=\Delta_4$、$Dq=-2$、フューター多項式）と05（$C\ell_{0,3}(\mathbb R)\cong\mathbb H\oplus\mathbb H$、コーシー核）は執筆時に追加する
