# クリフォード解析

複素解析・四元数解析・クリフォード解析に関する記事シリーズです。

まだ記事はありません。検討の経緯と未解決の争点は[MEMO.md](MEMO.md)にまとめています。

## 構想

シリーズの出発点は、ラプラシアン$\Delta$の平方根として1階の微分演算子$D$を取ることです。クリフォード代数の生成元を係数として偏微分を束ねると$D^2=\Delta$が成り立ち、その核として正則関数が現れます。複素解析をこの形で組み直した上で、同じ枠組みを四元数、さらに一般次元のクリフォード代数へ持ち上げるという構成を取ります。

複素解析編は教科書の再構成を意図しません。「高次元に持ち上がるかどうか」を選別の基準とし、後半で必要になる部分に絞ります。逆に、通常は複素数の定義から来る約束事として扱われる事柄、たとえば関数の値が実部と虚部の2成分を持つことは、平方根を取る操作が値を2成分に強制するという形で説明が付きます。複素数の定義を前提とせずに$\mathbb C$が現れる筋道になり、[全体構想](../PLAN.md)の狙いである幾何代数ベースでの再構築に沿います。

有向積分を整備すると、グリーンの定理・ストークスの定理・発散定理が1つの式にまとまり、コーシーの積分定理・積分公式・留数がその特別な場合として得られます。ここで現れる$2\pi$は$S^1$の周長であり、一般次元では$S^{n-1}$の面積に置き換わります。

シリーズの山場は四元数解析です。フューターの意味で正則な四元数値関数を考えると、複素解析では自明だった性質が次々と失われます。恒等写像すら正則ではなく、正則関数の積も合成も正則になりません。この破綻を通じて、複素解析の性質が**非可換性のせいで壊れるもの**と**次元のせいで壊れるもの**、そして**どちらでも壊れないもの**に仕分けられます。この仕分けがシリーズ全体の主張です。

一般次元のクリフォード解析は、四元数解析を特別な場合として回収する位置づけです。$C\ell_{0,3}(\mathbb R)\cong\mathbb H\oplus\mathbb H$という分解によって、四元数がどの部分にあたるのかが説明されます。

八元数解析は扱いません。非結合性のため、作用素の左右の作用が結合子で絡んで枠組みが立たないためです。曲がった空間上のディラック作用素（スピン構造・スピン接続）も範囲外とし、[全体構想](../PLAN.md)の「K理論と指数定理」に委ねます。

以上は現時点での構想であり、実際の記事構成は変更される可能性があります。
