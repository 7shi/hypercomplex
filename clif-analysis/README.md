# クリフォード解析

複素解析・四元数解析・クリフォード解析に関する記事シリーズです。

## 記事

1. [ディラック作用素とモノジェニック関数](01-dirac-monogenic.md) — $\operatorname{Cl}_{2,0}(\mathbb R)$の生成元でラプラシアンの平方根となるディラック作用素を構成し、偶部分代数に値を取る関数ではその核がコーシー＝リーマンの方程式で特徴づけられることを示します。関数の値が2成分を持つことを、作用素が作用する極小左イデアルの次元として説明します。
2. [有向積分と幾何微積分の基本定理](02-fundamental-theorem.md) — 1変数の微積分学の基本定理を、ディラック作用素と外向きの法線の積により多次元へ持ち上げます。平面のグリーンの定理、空間の発散定理とストークスの定理が、領域の基本定理とその曲面版という2つの式のグレード成分として得られることを示します。
3. [コーシーの積分定理・積分公式・留数](03-cauchy-residue.md) — 基本定理にモノジェニック性を代入して積分定理を、ベクトルの逆元$\boldsymbol x^{-1}$を核として積分公式を導きます。小円の上で核と法線の積が半径の逆数になることから、$2\pi i$の$2\pi$が$S^1$の長さとして、$i$が接線を法線に回す擬スカラーとして現れることを示します。留数は小円上の積分として定義します。
4. [四元数解析](04-quaternion.md) — $\operatorname{Cl}_{4,0}(\mathbb R)$の位置ベクトルに$e_0$を掛けて、四元数の変数とフューター作用素を作ります。恒等写像と逆元が正則でないことは次元に、正則関数の積が正則でないことは非可換性に由来することを示し、フューターの定理で$1/z$からコーシー＝フューター核を得ます。成分の調和性、積分公式、平均値の性質は、核と定数を取り替えて成り立ちます。
5. [一般次元のクリフォード解析](05-clifford.md) — $n$次元で、コーシー核$\boldsymbol x/|\boldsymbol x|^n$と正規化定数$|S^{n-1}|=2\pi^{n/2}/\Gamma(n/2)$による積分公式と留数を述べ、$2\pi i$が球面の面積と擬スカラーに分かれることを示します。恒等写像の正則性を壊す係数とフューターの定理のずれの係数がともに$n-2$であることから、$1/z$から核を作る作用素$\Delta^{(n-2)/2}$（フューター＝ソーの定理）を導きます。
6. [複素解析の性質の仕分け](06-summary.md) — 2次元に固有の事情を、変数そのものが正則になること（次元）と偶部分代数が可換であること（非可換性）の2つにまとめ、複素解析の性質をどちらで壊れるかによって仕分けます。恒等写像・逆元と合成は次元で、積と左右の正則性の一致は非可換性で壊れ、冪級数は両方にかかわります。積分公式と留数は核と定数が替わるだけで形を保ち、成分の調和性・平均値の性質・最大値原理はどの次元でも成り立ちます。

検討の経緯と未解決の争点は[MEMO.md](MEMO.md)にまとめています。

## 構想

シリーズの出発点は、ラプラシアン$\Delta$の平方根として1階の微分演算子$D$を取ることです。クリフォード代数の生成元を係数として偏微分を束ねると$D^2=\Delta$が成り立ち、その核として正則関数が現れます。複素解析をこの形で組み直した上で、同じ枠組みを四元数、さらに一般次元のクリフォード代数へ持ち上げるという構成を取ります。

複素解析編は教科書の再構成を意図しません。「高次元に持ち上がるかどうか」を選別の基準とし、後半で必要になる部分に絞ります。逆に、通常は複素数の定義から来る約束事として扱われる事柄、たとえば関数の値が実部と虚部の2成分を持つことは、平方根を取る操作が値を2成分に強制するという形で説明が付きます。複素数の定義を前提とせずに$\mathbb C$が現れる筋道になり、[全体構想](../PLAN.md)の狙いである幾何代数ベースでの再構築に沿います。

有向積分を整備すると、グリーンの定理・ストークスの定理・発散定理が基本定理のグレード成分としてまとまり、コーシーの積分定理・積分公式・留数がその特別な場合として得られます。ここで現れる$2\pi$は$S^1$の周長であり、一般次元では$S^{n-1}$の面積に置き換わります。

シリーズの山場は四元数解析です。フューターの意味で正則な四元数値関数を考えると、複素解析では自明だった性質が次々と失われます。恒等写像すら正則ではなく、正則関数の積も合成も正則になりません。この破綻を通じて、複素解析の性質が**非可換性のせいで壊れるもの**と**次元のせいで壊れるもの**、そして**どちらでも壊れないもの**に仕分けられます。この仕分けがシリーズ全体の主張です。

四元数は、$\operatorname{Cl}_{4,0}(\mathbb R)$の偶部分代数$\operatorname{Cl}_{4,0}^0(\mathbb R)\cong\operatorname{Cl}_{0,3}(\mathbb R)\cong\mathbb H\oplus\mathbb H$の片方として現れます。一般次元のクリフォード解析は、四元数解析を特別な場合として回収する位置づけです。

八元数解析は扱いません。非結合性のため、作用素の左右の作用が結合子で絡み、本シリーズの積の操作をそのまま移せないためです（八元数解析の理論自体は存在します）。曲がった空間上のディラック作用素（スピン構造・スピン接続）も範囲外とし、[全体構想](../PLAN.md)の「K理論と指数定理」に委ねます。

以上は現時点での構想であり、実際の記事構成は変更される可能性があります。
