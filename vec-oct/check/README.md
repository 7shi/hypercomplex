# 検証コード

プロジェクトルートで `uv sync` により環境を構築し、`uv run vec-oct/check/<ファイル名>` で実行します。

- [01-reflection.py](01-reflection.py) — 記事1の各代数系（ベクトル・複素数・純虚四元数・四元数・純虚八元数・八元数・$\operatorname{Cl}_{n,0}(\mathbb R)$）の内積と鏡映の公式、7次元鏡映が4次元鏡映を含むこと（実部を$e_4$へ）、鏡映の合成と回転の式、射影行列の冪等性、3次元の線対称な鏡映が軸周りの180度回転であることを確認します。
- [02-rotation.py](02-rotation.py) — 記事2の八元数に関する主張の数値検証。鏡映の合成と挟み込み$(nm)v(mn)$の分離、等傾三重回転の回転面と回転角、自己同型となる条件（$r^3\in\mathbb R$）と$\mathrm{Der}(\mathbb O)=14$次元、各操作が生成するリー代数の次元（挟み込み21・片側乗算28）、片側乗算の等傾四重回転、$rxr$・$rxr^*$の回転面、合成が畳めないことを確認します。
