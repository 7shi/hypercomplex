# 時空代数とディラック方程式

パウリ方程式からディラック方程式への流れを、実クリフォード代数で扱う記事シリーズです（準備中）。

検討の経緯は[MEMO.md](MEMO.md)にまとめています。

## 構想

想定読者は、[幾何代数による電磁気学](../em/README.md)シリーズで時空代数とローレンツ変換の回転子に馴染んだ人です。量子力学はシュレーディンガー方程式と確率解釈を知っている程度を前提とし、スピンは本シリーズで導入します。

標準的な定式化では、スピノルは複素数を成分とする列ベクトルで、パウリ行列やガンマ行列がそれに作用します。本シリーズでは、スピノルを偶部分代数の元として扱うHestenes形式を採ります。パウリスピノルは四元数そのものであり、ディラックスピノルは時空代数$\operatorname{Cl}_{1,3}(\mathbb R)$の偶部分代数（双四元数）の元です。どちらも密度と回転子の積に分解でき、回転子が基底を回した枠から、流れやスピンの向きといった観測量が読み取れます。

シリーズの軸は、量子力学の虚数単位$i$の読み替えです。Hestenes形式では、$i$はスピノルに右から掛かる2ベクトルとして現れます。大域位相はスピン軸まわりの回転（ホップファイバー）であり、ゲージ変換はその局所化です。左からの作用（ローレンツ変換）と右からの作用（位相と枠の選択）を区別することで、行列形式では見えにくい幾何的な意味を取り出します。

前半は3次元の$\operatorname{Cl}_{3,0}(\mathbb R)$でパウリスピノルとパウリ方程式を扱い、後半で時空代数に上げてディラック方程式に至ります。電磁場との結合を経て非相対論極限でパウリ方程式に戻り、スピンの磁気モーメントの係数$g=2$を回収します。

曲がった時空のディラック作用素、場の量子化、多粒子の系は本シリーズでは扱いません。
