# 時空代数とディラック方程式

パウリ方程式からディラック方程式への流れを、実クリフォード代数で扱う記事シリーズです（全5回）。

## 記事

1. [パウリスピノルとパウリ方程式](01-pauli.md)：列ベクトルのパウリスピノルを偶部分代数（四元数）の元に移し、虚数単位$i$が右から掛かる2ベクトル$\omega\sigma_3$になることを示します。確率密度とスピンの向きを$\psi\tilde\psi$と$\psi\sigma_3\tilde\psi$として読み、一様な磁場の中のスピンの歳差を回転子の時間発展として解きます。
2. [時空スピノルとSL(2,C)](02-spinor.md)：時空代数の偶部分代数（双四元数）の元としてディラックスピノルを導入し、回転子の群$\operatorname{Spin}^+(1,3)\cong\operatorname{SL}(2,\mathbb C)$が$\operatorname{SO}^+(1,3)$を二重に覆うことを示します。スピノルを密度・角・回転子に分解し、流れとスピンの向きを回転子の作る枠から読み取ります。
3. [ディラック方程式](03-dirac.md)：$\square$の平方根$D$からディラック方程式$\hbar D\psi\,\omega\sigma_3=mc\,\psi\gamma_0$を作り、行列形式と対応させます。右からの因子が左からのローレンツ変換と干渉しないことから共変性を示し、正と負のエネルギーの平面波解を求めます。
4. [電磁場との結合とゲージ変換](04-coupling.md)：最小結合で電磁場を加え、ゲージ変換が右からの回転子として流れとスピンの向きを変えずに枠を回すことを示します。流れの保存と、右からの$\sigma_1$による電荷の反転も扱います。
5. [非相対論極限とg=2](05-limit.md)：スピノルを時間軸と可換な部分と反可換な部分に分け、小さい成分を消去してパウリ方程式を回収します。幾何積の外積の部分が磁場の2ベクトルとなり、係数$g=2$を与えます。

検討の経緯は[MEMO.md](MEMO.md)にまとめています。

## 構想

想定読者は、[幾何代数による電磁気学](../em/README.md)シリーズで時空代数とローレンツ変換の回転子に馴染んだ人です。量子力学はシュレーディンガー方程式と確率解釈を知っている程度を前提とし、スピンは本シリーズで導入します。

標準的な定式化では、スピノルは複素数を成分とする列ベクトルで、パウリ行列やガンマ行列がそれに作用します。本シリーズでは、スピノルを偶部分代数の元として扱うHestenes形式を採ります。パウリスピノルは四元数そのものであり、ディラックスピノルは時空代数$\operatorname{Cl}_{1,3}(\mathbb R)$の偶部分代数（双四元数）の元です。どちらも密度と回転子の積に分解でき、回転子が基底を回した枠から、流れやスピンの向きといった観測量が読み取れます。

シリーズの軸は、量子力学の虚数単位$i$の読み替えです。Hestenes形式では、$i$はスピノルに右から掛かる2ベクトルとして現れます。大域位相はスピン軸まわりの回転（ホップファイバー）であり、ゲージ変換はその局所化です。左からの作用（ローレンツ変換）と右からの作用（位相と枠の選択）を区別することで、行列形式では見えにくい幾何的な意味を取り出します。

前半は3次元の$\operatorname{Cl}_{3,0}(\mathbb R)$でパウリスピノルとパウリ方程式を扱い、後半で時空代数に上げてディラック方程式に至ります。電磁場との結合を経て非相対論極限でパウリ方程式に戻り、スピンの磁気モーメントの係数$g=2$を回収します。

曲がった時空のディラック作用素、場の量子化、多粒子の系は本シリーズでは扱いません。
