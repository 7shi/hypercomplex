# 検証コード

時空代数とディラック方程式の記事の数式を検証するPythonスクリプトです。プロジェクトルートで `uv sync` により環境を構築し、`uv run dirac/check/<ファイル名>` で実行します。クリフォード代数の実装は`common.clifford`（`src/common/clifford.py`、$\operatorname{Cl}_{p,q}(\mathbb R)$のビットマスク実装）を使います。

- [01-pauli.py](01-pauli.py)：[01-pauli.md](../01-pauli.md)の数式。$\sigma_k\mapsto\hat\sigma_k$、$\omega\mapsto iI$と反転がエルミート共役に移ること、対応$\psi=a_0+\sum a_k\omega\sigma_k\mapsto\Psi=(a_0+ia_3,-a_2+ia_1)^T$が$\hat\psi$の第1列で全単射なこと、$\hat\sigma_k\Psi\leftrightarrow\sigma_k\psi\sigma_3$、$i\Psi\leftrightarrow\psi\,\omega\sigma_3$、$\psi P=(\Psi,0)$と$\omega\sigma_3P=\omega P$、$\psi\tilde\psi=\Psi^\dagger\Psi$、$\psi\sigma_3\tilde\psi$の成分$\Psi^\dagger\hat\sigma_k\Psi$と位相による不変性、四元数の関係と$\sigma_3=\omega\mathbf k$、運動量と$\hat{\boldsymbol\sigma}\cdot\boldsymbol B$の翻訳、一様な磁場の中の歳差（角速度$-gqB/2m$、行列形式との照合）を確認します。第2列の形、例の対角行列、位相による枠$e_1,e_2$の回転、$g=2$の回転子がem/05の磁場の回転子と一致することも確認します。
- [02-spinor.py](02-spinor.py)：[02-spinor.md](../02-spinor.md)の数式。偶部分代数から$M_2(\mathbb C)$への準同型、時空の反転が余因子行列・$X\tilde X$が行列式・$\gamma_0\tilde X\gamma_0$がエルミート共役に対応すること、$(Rx\tilde R)\gamma_0\leftrightarrow\hat R\hat X\hat R^\dagger$、ベクトルと可換な偶部分の元がスカラーだけなこと、$2\pi$回転の回転子が$-1$、ブーストの回転子$B=(1+u\gamma_0)/\sqrt{2(1+u\cdot\gamma_0)}$、$\gamma_0$と可換な偶部分の元が$1,\omega\sigma_k$で張られること、分解$\psi=\sqrt\rho\,e^{\omega\beta/2}R$と$\psi\gamma_\mu\tilde\psi=\rho e_\mu$（乱数の例）を確認します。パウリスピノルについて$\psi\sigma_3\tilde\psi=(\psi\gamma_3\tilde\psi)\gamma_0$、$B$が正定値エルミート行列に対応すること、$e^{\omega\sigma_3\alpha}$が$\gamma_0,\gamma_3$を動かさないことも確認します。
- [03-dirac.py](03-dirac.py)：[03-dirac.md](../03-dirac.md)の数式。標準的なディラック表現と対応$\psi=\phi+\eta\sigma_3\mapsto(|\phi\rangle,|\eta\rangle)^T$について$\hat\gamma_\mu\Psi\leftrightarrow\gamma_\mu\psi\gamma_0$、$i\Psi\leftrightarrow\psi\,\omega\sigma_3$、$\hat\gamma_5\Psi\leftrightarrow\psi\sigma_3$、電磁場を含む方程式の同値性（記号関数）、クライン＝ゴルドン方程式への帰着、平面波$\psi_0e^{-\omega\sigma_3p\cdot x/\hbar}$と静止・運動・負のエネルギーの解、共変性$D[R\psi(\tilde RxR)]=R(D\psi)(\tilde RxR)$、行列形式の2次式$\Psi^\dagger\Psi$・$\bar\Psi\Psi$・$\bar\Psi\hat\gamma^\mu\Psi$・$\bar\Psi i\hat\gamma_5\Psi$との対応を確認します。ワイル射影と平面波の$\beta$・流れも確認します。
- [04-coupling.py](04-coupling.py)：[04-coupling.md](../04-coupling.md)の数式。ゲージ変換$A\mapsto A+D\chi$、$\psi\mapsto\psi e^{\omega\sigma_3\alpha}$（$\alpha=-q\chi/\hbar c$）で方程式が保たれること（記号関数）、位相による枠の変換、$\langle D(\psi\gamma_0\tilde\psi)\rangle_0=2\langle(D\psi)\gamma_0\tilde\psi\rangle_0$と質量・結合の項がスカラー部に寄与しないこと、$J$が未来向きの時間的ベクトルであること、右からの$\sigma_1$が電荷の符号を反転し流れを変えないことを確認します。
- [05-limit.py](05-limit.py)：[05-limit.md](../05-limit.md)の数式。静止エネルギーを分離した分割した方程式（記号関数）、$\Pi$が$\gamma_0$と可換な部分と反可換な部分を入れ替えること、$D_3\boldsymbol A=\nabla\cdot\boldsymbol A+\omega\boldsymbol B$と$\Pi^2$の展開、$\operatorname{Cl}_{3,0}(\mathbb R)$での行列形式との照合（$(\Pi X)\sigma_3\leftrightarrow\hat{\boldsymbol\sigma}\cdot\hat{\boldsymbol\pi}\Psi$、$\Pi^2\leftrightarrow\hat{\boldsymbol\pi}^2-q\hbar\hat{\boldsymbol\sigma}\cdot\boldsymbol B$）、自由粒子の平面波の小さい成分の比$p/(mc+E/c)$を確認します。
