# 検証コード

プロジェクトルートで `uv sync` により環境を構築し、`uv run oct/check/<ファイル名>` で実行します。`src/common/octonion.py`は各検証スクリプトが共通で使う八元数の積演算モジュールです。

- [03-lxp-recovery.py](03-lxp-recovery.py) — 復元式 $L_x = \sum_{j=0}^{7} R_j (L_x P) R_j^{-1}$ の数値検証。各項が$L_x$の第$j$列を再現すること、右作用$R_1$が左作用の積の線形結合で書けることも確認します。
- [03-p-fano-group.py](03-p-fano-group.py) — 射影行列$P$の8項（$I$とファノ7直線の三重積）が位数8の可換群を成すことの数値検証。群の閉性、単位元の固定、共点3直線の乗積規則、剰余類$L_kG$による64基底の分類を確認します。
- [03-l1l2p-to-l3.py](03-l1l2p-to-l3.py) — $L_1L_2 \ne L_3$ の具体例で、射影$L_1L_2P = L_3P$と復元式による$L_3$の再構成を行列表示で確認します。
- [03-p-inline-expand.py](03-p-inline-expand.py) — 行列を使わない代数計算のシミュレート。$L_7$を記号のまま反交換で扱い、$P$をインライン展開した$L_1L_2P$と$L_3P$が同じ8項（分類表の$e_3$行）に一致することを項別に確認します。4文字以上の語は体積関係式$L_1\cdots L_7=-I$で3文字以下の補集合に畳み込みます。
- [03-8lip.py](03-8lip.py) — $8L_xP$を構成する8つの項が個別に単位元$1$を$e_x$へ送ることの検証。$PP \mapsto 1$および$L_xP \mapsto e_x$の項ごとの裏付けと、8本の等式$8L_xP = \dots$の確認を行います。
- [03-liri-form.py](03-liri-form.py) — 射影$P$を四元数と同様の$L_iR_i$形式で書けるかの検証。$L_iR_i$が結合性によらず対角行列（位置$0$と$i$が$-1$、他が$+1$）になることを確かめ、生成元の個数$n$についての一般公式$a=\frac{1}{2-2n},\,a_0=(2-n)a$を導いて、四元数（$n=3$）で係数がそろうのは偶然であり、八元数（$n=7$）では$P=\frac{1}{12}(5I-\sum_{i=1}^7 L_iR_i)$と不揃いになることを確認します。
- [04-sedenion.py](04-sedenion.py) — 04-sedenion.md の数式の数値検証。十六元数の基底の積規則（35個の三つ組・添字のXOR規則）、共役の反自己同型性と$xx^* = |x|^2$・両側逆元、冪結合性と柔軟法則、交代性の破れ、ノルムの乗法性の破れの公式$|xy|^2 = |x|^2|y|^2 + 2\,(d,a,c)\cdot b$と四元数の倍加では乗法性が保たれること、零因子$(e_1+e_{10})(e_5+e_{14})=0$と消去律の崩壊、モレノの特徴づけ（成分が直交する等ノルムの純虚ペア）と4次元の零化空間、基本三つ組$(u_1,u_2,u_3)$と零因子ペアの対応、$G_2$の対角持ち上げが十六元数の自己同型としてペアの空間に作用すること（固定部分群が自明・接空間14次元・軌道が全体を張ること）、$\dim\operatorname{Der}(\mathbb S) = 14$とすべてが対角持ち上げであること、離散自己同型$\varepsilon, \psi$と$S_3$の関係式を確認します。
